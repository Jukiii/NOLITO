ツール

NOLITO のツールは、日々の作業を自分の手順に合わせて整理するためのものです。現在公開中の「キーみち」では、使っているアプリのキー操作を登録し、作業の順番に並べて練習できます。

キーみちで操作ルートを作る

  1. まず、何度も行う作業を1つ選び、使うアプリと操作を書き出します。
  2. ショートカットは、アプリや OS のバージョン、設定によって違います。使っている環境のメニューや公式案内で確認してから登録してください。キーみちには、共通のショートカット辞書はありません。
  3. 操作を実際の作業順に並べ、練習画面でキーを思い出して押します。判定できないキーは答えを見て確認でき、練習結果は保存されません。
  4. 手順を印刷や Markdown のチートシートにして使い、アプリの設定や作業手順が変わったら登録内容も見直します。データはブラウザ内に保存されるため、必要に応じて JSON でバックアップしてください。

キーみちの機能・保存方法・対応環境を詳しく見る。 手順の登録から練習までの画面操作は、キーみちの使い方ガイドで確認できます。
