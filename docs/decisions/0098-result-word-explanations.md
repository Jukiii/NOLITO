# 0098 結果画面で、表示した全語の説明を出す

日付: 2026-10-07 / 対象: Issue #240

## 背景

連続タイピングの結果画面では、ミスした語だけを説明つきで表示していた。運営者から、ミスの有無にかかわらず、出てきた語すべての解説を見たいとの依頼があった。

## 決定

- 結果画面の語一覧は「今回出てきた語」とし、そのプレイで実際に表示された語を出た順に並べる。ミスの有無にかかわらず、短い説明を表示し、関連用語・詳細説明・学習ポイントも既存の共通部品で表示する。
- ミス回数のバッジは維持し、ミスがない語には表示しない。まだ画面に出ていない語は含めない。
- 用語確認の結果・成績ページの復習リスト、記録・スコア・出題・プレイ中の説明設定は変更しない。
- 変更をゲームの更新履歴・FAQ・画面説明に反映する。

## 影響・確認

- 表示対象は現在表示中の語までとする。終了時にまだ出ていない後続語は一覧に加えない。
- `resultWords` の単体テストで、出た順・ミス回数・表示中の語・未表示語を確認する。画面配線のテストで、結果画面が全語一覧を共通部品で描くことを確認する。
- 用語の表示は引き続き `review-item.js` を使い、語録の文字列を HTML として解釈しない。
