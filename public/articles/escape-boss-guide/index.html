「上司から逃げろ」の遊び方とローマ字入力のコツ

  • ゲーム
  • タイピング

「上司から逃げろ」は、仕事や会社で使う言葉をローマ字で入力して、追ってくる上司から逃げ切るタイピングゲームです。登録は要りません。ブラウザですぐに遊べます。

遊び方

  1. ゲームのページで、職種と、追ってくる人(役職)を選びます。
  2. 画面に出る言葉を、ローマ字で入力します。
  3. 言葉を打ち終えると、逃走距離が増えます。決められた語数を打てば逃げ切りです。
  4. 時間がたつと距離が減り、打ち間違えても減ります。距離が 0 になると、つかまります。

職種は、エンジニア、営業、事務、飲食、講師・教育、接客販売の6つです。選んだ職種の用語が出ます。

役職ごとの違い

追ってくる人は、先輩・係長・部長・社長の4人から選べます。上の役職ほど、速く追ってきて、打ち間違えたときの減り方も大きくなります。そのぶん、クリアしたときのスコアも高くなります。

4人すべてをクリアすると、裏ボスの会長に挑戦できるようになります。

ローマ字入力のコツ

打ち方は、いくつかの書き方から選べます。

  • 「し」は si でも shi でも打てます。「ち」「つ」「ふ」「じ」も、同じように複数の書き方に対応しています。
  • 「しゃ」「ちゅ」などは sha でも sya でも打てます。
  • 「っ」は、次の子音を重ねます。「こみっと」は komitto です。
  • 「ー」(伸ばす音)は、ハイフン - を押します。「さーばー」は sa-ba- です。
  • 「ん」は、次が母音やや行のときと、言葉の最後では nn と打ちます。それ以外の場合は n でも nn でも大丈夫です。「こんにちは」は konnichiha、「ほうもん」は houmonn です。

日本語入力(IME)がオンだと、文字が変換の途中になって判定できません。オフにして、半角英数で入力してください。

成績を見て、苦手を知る

遊んだ記録は、成績のページで見られます。

  • 入力速度・正確率・スコアの推移を、グラフで確認できます。
  • どのキーで打ち間違えやすいかが、ミス率の高い順に表示されます。
  • 1回遊ぶたびに、結果の画面で、そのプレイのミスしたキーも確認できます。

記録の保存について

成績や称号などの記録は、お使いの端末(ブラウザ)の中にだけ保存されます。ほかの端末には引き継がれません。ブラウザの保存データを削除すると、記録も消えます。

まずは先輩から、気軽に遊んでみてください。
