# 0073 スタート前の「職種・追ってくる人」の選択欄が、使えなくなっていた不具合の修正(Issue #173)

## 理由

Issue #173「職種と難易度が選べなくなった」の報告。調べると、原因は 2 つあった。

1. **PR 5(0071)で、プレイ中の入力欄を画面から隠す規則(1px に切り抜く)を、クラス `.game-input__field` に直接書いた**。このクラスは、スタート前の「職種」「追ってくる人」の選択欄・「くわしい設定」の欄・成績ページの絞り込み・プロフィールの欄も使っていたため、これらもすべて 1px に隠れた(選べない)。
2. **PR 1(Issue #166 のアーケード風化)から、`.game-input__field` の背景が固定の暗い色(`--arcade-bg`)** だった。プレイ画面の外(明るいページ)では、暗い背景に暗い文字になり、選択欄が読めなかった。

## 変更

- `game.css`: `.game-input__field`・`.game-input__label` の、通常の見た目を戻した(背景は、ページの面の色 `--color-surface`。プレイ画面の中では、アーケードの暗いパネルになる)。**隠す規則は、`.game-input`(プレイ画面の入力欄)の中だけ**(`.game-input .game-input__field`)に限った。横向きの低い画面の、欄の高さ・ラベルの文字の規則も戻した。
- テスト(`tests/sprite-scene.test.js`): 隠す規則が、必ず `.game-input` の中に限られること、設定の選択欄が HTML に残ること、選択欄が暗い固定色にならないこと。

## 影響範囲

- 記録・ランキング・ゲームのロジック・語録・バランスは変えない。プレイ中の入力欄は、これまでどおり隠れて、フォーカスを受ける。
- 今後、`.game-input__field` を使う欄を足すときは、隠す規則の影響を受けない(`.game-input` の外に置く)。

## 未対応

- 「ここからゲーム感を出してほしい」(スタート前の画面を、ゲームらしくする)は、別の PR で対応する。
