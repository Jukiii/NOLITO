# 0058: 4 つのテーマの採用(Phase 31)

## 背景

デザイン見本(0057。`/theme-preview/`)を見た運営者が、次の 4 つを採用して、テーマとして選べるようにすることを決めた(Issue #136 への回答)。

| 名前(画面) | 見本での名前 | 中身 |
| ------------ | ------------ | ---- |
| デフォルト | 今のまま | これまでのライト(クリーム色・紫・黄色) |
| ホワイト | ホワイト | 白と灰色・青。細い線とやわらかい影 |
| ダーク | クール | 濃い紺・水色・すみれ色。角が小さく、縁が光る |
| プリティ | 可愛い | ピンク・大きな丸み・やわらかい影 |

メタリックは、採用しない。以前の「ダーク」(暗い茶色)は、クールに置き換える。

## 決定

- **テーマの値**: `theme.js` の `THEMES` = `light`(デフォルト)・`white`・`dark`(クール)・`pretty`・`system`。保存のキー(`nolito:theme:v1`)・既定(`system`)・`data-theme` は、これまでのまま。保存済みの `light` / `dark` は、そのまま有効(`dark` の見た目だけが変わる)。
- **`system`**: OS がライトならデフォルト、OS がダークなら「ダーク」(クール)に追従する。ホワイト・プリティを明示して選んだ場合は、OS がダークでも、そのまま(`tokens.css` の `@media (prefers-color-scheme: dark)` の対象から除く)。
- **色・形は `tokens.css` の `:root[data-theme="…"]`**(色に加え、線の太さ・角の丸み・影)。ボタンの影は、新しいトークン `--shadow-primary` で、テーマごとに変える(`components.css` の `.button--primary`)。**新しい色トークンは、影・光(`--color-shadow`・`--color-glow`)だけ**。
- **アクセント色は、共通ではなくなった**(ホワイト = 灰色・ダーク = すみれ色・プリティ = 薄いピンク)。0046 の「アクセントは、ライト・ダーク共通」は、この決定で置き換わる。
- **FOUC のスクリプト**: 25 ページ(手書き 24 + `render.mjs`)を、同じ内容に更新した(`/^(light|white|dark|pretty)$/.test(t)`。`system` は属性なし = OS 任せ)。
- **アカウントの同期**: サーバー側は `isTheme` をそのまま使うので、コードの変更は要らない(新しい値が、自動で許される)。古い端末(この変更より前の JS)が、`white` / `pretty` を含む設定をダウンロードしても、`isTheme` で弾かれて `system` になるだけで、壊れない。
- **見本ページ(`/theme-preview/`)**: 残す(比べた記録)。採用した 4 案が `tokens.css` と同じ値であることを、テストが検査する。「ダーク」(以前の暗い茶色)と「メタリック」は、見本だけに残る。
- **プライバシーポリシーの版は、上げない**(見た目の好みで、個人を特徴づけない。0046 と同じ判断)。

## 影響範囲

- 利用者: フッターの「テーマ」に、デフォルト・ホワイト・ダーク・プリティ・システムの 5 つ。`dark` を選んでいた人・OS がダークの人は、暗い茶色から、濃い紺に変わる。
- D1・環境変数・ポリシー: 変更なし。

## 既知の制限

- ゲームの場面の背景・キャラクターの絵は、ライト向けの配色のまま(0046・0057 のとおり。ダーク・プリティでも、絵そのものは変わらない。飾りで、操作には影響しない)。問題があれば、別 Issue。
- `/games/escape-boss/` は、375px 幅で、わずかに横にあふれる(384px。テーマに関係なく、以前からある。バックアップの読み込みの欄か、入力欄の幅が原因と見られる)。この PR では、直さない。

## テスト結果

- `npm run check` 通過。`tests/theme.test.js` が、4 テーマそれぞれの WCAG AA(文字 4.5:1・枠と焦点 3:1)・`system` のダークの対象の除外・FOUC のスクリプトを検査。`tests/theme-preview.test.js` が、採用した 4 案と本番の値の一致を検査。
- ヘッドレスの Edge で、5 つの切り替え・再読み込みでの保持・OS ダーク時の `system` と明示テーマの優先・375px 幅を確認した。
