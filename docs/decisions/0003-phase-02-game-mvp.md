# 0003 Phase 2 ゲームMVPの決定事項

日付: 2026-09-20 / 対象Phase: 2

## スコープ

Phase 2 は「最初に遊べる最小のゲーム」とする。職種を選び、先輩の1ステージを、連続タイピング型で遊べる。

含めないもの(該当Phase): 役職の選択・会長・称号・実績・ランキング(P3・17・18)、成績の保存・ミス分析・成長グラフ(P4・19)、
用語確認モード・復習リスト・説明の表示(P12)、苦手用語の出題調整・入力方式の設定UI(P13)、追跡アニメ・キャラ・BGM・効果音(P15・16・23)、
ソフトウェアキーボードの最適化(P22)。

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | ステージクリア | 8語正解でクリア。距離が 0 になるとゲームオーバー | 1プレイの長さが読みやすく(P4「1〜3分」)、重複なし出題と合う |
| 2 | バランス初期値(先輩) | 距離 0〜100、初期 60。時間経過 −1.5/秒。正解 +(5 + 0.6×ローマ字文字数)。ミス −3 | 仮置き。プレイして調整する。値は `public/data/roles.json` の `stage`(P17「後から修正可能」に備える) |
| 3 | ID体系 | 職種: `engineer` `sales` `office` `food-service` `teaching` `retail` / 役職: `senpai` `kakaricho` `buchou` `shachou` `kaicho`(Phase 2 で使うのは `senpai` のみ) | 後から変えにくいため先に確定 |
| 4 | 語録 | 6職種 × 10語の**下書き**(`version: 0.1.0`)。難易度は 1〜3 を使用し、許容範囲は 1〜5 とする | 語録は人間の確認が必須(P14・24)。下書きはAIが作成し、ユーザーがPRで確認する |
| 5 | 語録の形式 | JSON を直接書く。項目は語録テンプレート(`docs/04_templates/vocabulary-template.md`)と同じ | Markdown→JSON変換は Phase 14 で導入(それまで管理元はJSON) |
| 6 | ローマ字入力 | 読み(`reading`)から複数の表記を自動で許容。語録の `romaji` は候補の宣言で、全候補が受理されることをテストで検証 | 設定UIは Phase 13。し=si/shi、ん=n/nn/xn、っ=子音の重ね、拗音、長音(`-`)に対応 |
| 7 | ん の扱い | 子音・な行の前は `n` でも `nn` でもよい。母音・や行の前と語末は `nn` が必須 | 一般的な日本語入力(こんにちは=konnichiha)に合わせる。語末を `n` だけで確定すると、`nn` と打つ人の2文字目が次の語へ漏れるため |
| 8 | URLとナビ | `/games/escape-boss/`。`/games/` に一覧(ProductCard 1枚、バッジは「テスト版」)を追加し、ナビの「ゲーム」を有効化。トップページは変更しない | 一覧はPhase 20 で拡張 |
| 9 | 入力の受け取り | `<input>` の `input` イベントで値を読み、読んだら空に戻す。IME オンは警告を表示 | スマホのソフトウェアキーボードで keydown の key が取れない場合があるため |
| 10 | テスト | Node 標準の `node --test`(依存なし)。`npm run test` を `npm run check` と CI に含める。`engines.node` を `>=22` に引き上げ | `--test` のグロブ指定が Node 21 以降のため(CI は Node 22) |
| 11 | 一時停止 | タブが見えない間はゲームを進めない。1フレームの進行は最大0.1秒 | 戻ったときに距離が一気に減るのを防ぐ |
| 12 | 仕様書からの構成変更 | バランス値は `config.js` ではなく `roles.json` に置く。画面は `ui.js` ではなく `view.js` と `input.js` に分ける | データ駆動にするため / 責務の分離 |

## バランスの試算(実際の語録とエンジンによるシミュレーション)

語のローマ字文字数は平均7.9(4〜13)。打鍵速度ごとに、1打鍵あたりミス率 5〜8% で各3000回試行した。

| 案 | 遅い(1.2打鍵/秒) | ふつう(2.5) | 速い(4) |
| -- | ---- | ---- | ---- |
| **A 現在(8語・減少1.5/s・増加5+0.6n)** | クリア91%・65秒 | 100%・35秒 | 100%・23秒(残り距離93) |
| B 減少2.5/s | 0% | 99%・35秒(残り35) | 100%・23秒(残り70) |
| C 12語・減少2.5/s | 0% | 83%・52秒 | 100%・35秒 |
| D 12語・減少3/s・増加4+0.5n | 0% | 0% | 99%・35秒 |

- 承認済みの A は、先輩(最初のステージ)として遅い人にも遊べる。一方、平均で 23〜65 秒と、Phase 4 の「1プレイ 1〜3分」より短く、速い人は距離がほぼ最大のままで緊張感がない
- 減少を強めるほど、遅い人がクリアできなくなる。**1つのステージで全員に合わせるのは難しい**ため、難しさは役職ごとのパラメータ(P12・17)で作る方針が合う
- 1〜3分に近づけるには、1回の語数を増やす必要がある(15語前後)。現在は職種ごとに10語のため、語録の拡充(P14・24)とセットで見直す
- 結論: Phase 2 では A のまま公開し、実際にプレイした感想と語録の拡充を踏まえて調整する
