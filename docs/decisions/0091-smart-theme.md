# 0091: テーマ「スマート」を足す(Phase 32)

日付: 2026-10-04

## 経緯

Jさんから、「https://fourcard-game.satouumaiyo.workers.dev/ このサイトみたいにスマートな感じにして」という依頼があった。参考のサイトは、白い背景・余白の多いミニマル・矩形のボタン・細い線・番号つきの見出し・「↗」の矢印が特徴。適用範囲を確認したところ、Jさんは「新しいテーマとして足す」を選んだ(既存の 4 テーマは、そのまま残す)。

## 変えたこと

- テーマの値に **`smart`(スマート)**を足した(`theme.js` の `THEMES`・フッターの選択欄 `footer.js`)。保存のキー `nolito:theme:v1`・既定(`system`)は変えない。
- 配色・形は `tokens.css` の `:root[data-theme="smart"]` が持つ(ほかのテーマと同じ作り)。
  - 色: 背景・面は白、文字は `#111`、薄い文字は `#555`、プライマリは黒(ホバーは `#333`)、アクセント・やわらかい面は薄い灰色。
  - 形: 線は 1px の黒、角の丸みは 0(矩形)、影はなし(`--shadow-*` は `none`)。
- 「システム」で OS がダークのときも、スマートを選んでいれば、ダークにならない(`@media` の `:not()` の一覧に足した)。
- ちらつき防止(FOUC)のスクリプトの正規表現を、全ページと `scripts/lib/render.mjs` で `(light|white|dark|pretty|smart)` に直した。
- `tests/theme.test.js` を、5 テーマ・6 つの値に合わせた(コントラスト比 AA・形のトークン・FOUC・選択肢)。

## 変えないこと

- 既存の 4 テーマ(デフォルト・ホワイト・ダーク・プリティ)の値。ゲームのアーケード風の画面(`--arcade-*`。テーマでは上書きしない)。
- レイアウト・見出し・文言。参考のサイトにある「番号つきの見出し」「↗ の矢印」は、このテーマでは入れない(テーマは色と形のトークンだけを変える決まりのため。入れるなら別の依頼で、サイト全体の変更として Issue で確認する)。
- プライバシーポリシーの版(テーマの好みは、個人を特徴づける情報ではない。決定 0046 と同じ判断)。テーマのアカウント同期(`isTheme` を共有)は、そのまま `smart` も受け付ける。

## テスト

- `npm run check`(2347 件)が通る。スマートの色の組み合わせは、WCAG AA(本文 4.5:1・枠線とフォーカス 3:1)を、テストが実際の `tokens.css` の値から検査する。
- 実ブラウザでの見た目は、Jさんの確認が要る(下の「Jさんの作業」)。

## 既知の制限

- 見た目の細かい調整(余白・文字の太さなど)は、テーマのトークンだけでは、参考のサイトと同じにならない。Jさんの確認のあと、必要なら別の依頼で直す。
