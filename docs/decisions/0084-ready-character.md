# 0084: 準備の画面に、あなたのキャラクターと一言を出す(Issue #173)

## 背景

Issue #173 で、Jさんから「待機画面用のキャラクターを用意してコメントしてる感じにして」と依頼があった(2026-10-03)。

## 決定

- 準備の枠(「PRESS SPACE KEY TO START」)の上に、あなたのキャラクター(場面と同じ `player.svg` のコマ送り)と、吹き出しの一言を出す。新しい絵は作らず、既存の絵を使う。
- 一言は `ready.js` の `READY_LINES`(10 個。1 つ 20 字まで。`lines.js` の `isValidLine` と同じ決め)から、準備に入るたびに 1 つ選ぶ(直前と同じ言葉は続けない。`pickReadyLine`)。冗談は軽い範囲にする。**AI の下書きで、Jさんの確認待ち**(0031 のセリフと同じ扱い)。
- キャラクターと吹き出しは飾り(`aria-hidden`)。日本語の案内(スペースキーで始まる・IME をオフ)は、これまでどおり文字で残す。文字は `textContent` だけで入れる。
- 動きを減らす設定では、絵は 1 コマ目で止まる(既存の規則)。用語確認には準備がないので、出ない。

## 影響

- 記録・設定・保存の形は変えない。距離・バランス・語録は変えない。
- `tests/sprite-scene.test.js` の、画面の絵の枚数を 3 → 4 に直した(準備の画面のあなたの絵)。
- 見た目の確認: 幅 1200px・360px(ヘッドレス Edge)で、横にはみ出さないこと。

## 未対応

- 一言の文面は、Jさんの確認後に直す。
- `public/assets/img/products/escape-boss/` の画面(スタート・プレイ中など)の撮り直しは、準備の画面を撮ったものがないため、していない。
