# 0093: 語録の増量 バッチ 4 の下書き

日付: 2026-10-04

## 背景

職種ごとに 300 語以上にする目標について、バッチ 3(0092)の次の追加を進める。運営者の確認前の語は公開せず、原稿に下書きとして置く。

## 決めたこと

- `content/vocabulary/<職種ID>.ext-batch4.md` に、エンジニア 148 語・営業 145 語・事務 137 語・飲食 148 語・講師・教育 137 語・接客販売 146 語、計 861 語を追加した。
- 職種ごとの指定数の合計は 861 語(870 語ではない)。原稿の開始時の語数は順に 152・155・163・152・163・154 語で、追加後は各職種ちょうど 300 語。
- id は既存の最大 id の次から連番にした。日本語表記と読みは、既存原稿・追加語のすべてと重複しない。
- すべて `draft: true` / `review: pending`。運営者が確認した語だけ公開する。確認済みにしたり、公開したりしない。
- 既存の語・バッチ 3・公開 JSON・`products.json`・役職のバランスは変更しない。

## 影響

- 語録原稿は合計 1,800 語(6 職種 × 300 語)、下書きは合計 1,277 語。公開は引き続き 523 語で、ゲームの出題・クリア率は変わらない。
- `npm run vocab:check` は形式の検証を通過した。説明の類似候補 40 件は確認の目安で、重複と断定しない。`npm run vocab:stats` の警告は 0 件。
- 公開するときは、`tests/balance.test.js` でクリア率を確認し、必要に応じて語録の版・ゲームの更新履歴・役職のバランスを見直す。

## 次

確認シートで人間が確認 → OK の語だけ公開 → 公開前にバランスを再確認する。
