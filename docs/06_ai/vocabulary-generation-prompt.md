# AI用語録生成プロンプト

指定された職種について、タイピング練習用の単語・用語を、**`docs/04_templates/vocabulary-template.md` の形式の YAML**(` ```yaml ` で囲む)で生成すること。

- 日本語、読み仮名(ひらがなと長音だけ)、カテゴリ、難易度(読みの長さの決め: 単位数 3 以下 = 1、4〜5 = 2、6 以上 = 3)、対象役職、短い説明(「。」で終わる 1 行、80 字以内)、関連用語(同じ職種の、ほかの語)、学習ポイント、苦手判定情報(`weak_detection`)を含める。
- **ローマ字(`romaji`)は書かない**(読みから、自動で作られる)。
- **すべての語に、`draft: true` と `review: pending` を付ける**。既存の語の `id` は変えず、新しい `id` は、続きの番号にする。
- 一般に確立した意味だけを書く。**推測で専門用語の意味を作らず、不明点・会社や地域で違う点・法令や制度に関わる点は、`note` に書いて、確認対象として明示する**。ブランド名・製品名は書かない。
- 出力後は、必ず人間が、内容・正確性・表記・難易度・不適切表現を確認する(AI の出力は、下書き)。
