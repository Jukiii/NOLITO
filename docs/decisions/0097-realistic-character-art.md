# 0097 キャラクターを写実寄りの画像素材にする

日付: 2026-10-06 / 対象: Issue #235

## 背景

運営者から「デフォルメじゃない」「写実的にする」「画像素材で」「画像も作って欲しい」と要望があり、素材の新規作成も依頼された。写真のような画像生成機能は使えないため、外部素材を持ち込まず、自然な頭身のオリジナルイラストをローカルで作る。

## 決定

- 追う側 5 役職とプレイヤー 2 種(通常・ピンチ時)を、陰影・顔・衣服・乗り物を描いた透過 PNG の 6 コマ素材にする。写実寄りのイラストであり、写真ではない。
- PNG は論理寸法の 3 倍解像度にする(役職 2160×240、プレイヤー 1152×240)。表示の 6 コマ送り・モーション設定・役職の乗り物・ゲームロジックは変えない。
- 既存の SVG URL は、D1 のプロダクト情報などから参照されているため維持する。SVG は同一サイト内の PNG 素材だけを表示するラッパーにし、外部画像・外部通信は使わない。
- 元の配色・表情・頭身を含む「ポップなデフォルメ」の決定(0030)を置き換える。人間の描き方は、今後も大きな頭や目を誇張しない。
- 新しい絵を反映したプレイ中画面を、既存と同じ 1000×700 の `play.webp` に撮り直す。

## 影響・確認

- 新規素材は `public/assets/img/escape-boss/*-realistic.png`。既存の SVG パス・HTML・役職データの参照先は変えない。`public/assets/img/products/escape-boss/play.webp` も更新する。
- `tests/characters.test.js` で、素材の形式・解像度・透過・ローカル参照・通常/ピンチ素材の寸法を検査する。
- レイアウト・ゲーム進行・記録・音・役職選択は変更しない。
