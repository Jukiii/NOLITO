# 0029 Phase 15 PR 2: 職種別背景

日付: 2026-09-21 / 対象: Phase 15「…追跡アニメーション、役職専用演出、**職種別背景**。入力はすべてローマ字」。PR 1(0028: 画面構成と、役職専用の追跡アニメーション)の続きで、Phase 15 の最後の PR。

## 運営者が決めたこと(計画への「推奨案で」)

- **職種別背景**: 職種ごとに **SVG 1 枚**(CSS のグラデーションだけにはしない)
- **データの持ち方**: 背景は `jobs.json` に書く(動きは `roles.json`。0028)
- **背景を敷くのは場面の中だけ**。単語・入力欄には敷かない
- 絵は、いまの絵のまま(描き直しは Phase 16)

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 絵 | 6 職種に 1 枚ずつ、`public/assets/img/escape-boss/bg/<職種ID>.svg`。**360×112 の 1 枚を、場面の中で、横に繰り返す**(場面の高さ 7rem に合わせる。幅が変わっても、並べて埋まる)。エンジニア = モニターとサーバー / 営業 = ビル街 / 事務 = 机・窓・ファイル棚・観葉植物 / 飲食 = 厨房(吊るした鍋・皿・湯気)/ 講師・教育 = 黒板・机・時計 / 接客販売 = ひさしと、商品の棚。**各 1〜1.6KB(3KB 以内)** | 軽い。幅に関係なく、埋まる |
| 2 | 淡さ | 追ってくる人・自分の絵(濃い輪郭 `#1b2033`)が、**埋もれない**ように、淡い色だけを使う。すべての色が、**白・場面の地の色(`#fff1b8`)との明るさの比が 2.2 以下**、かつ**濃い輪郭との比が 3 以上**(テストで、色を 1 つずつ計算して検査)。ブラウザで、場面の中で、追ってくる人・自分の絵が、いちばん前に描かれることも確認 | 背景が、主役を邪魔しない |
| 3 | データ | `jobs.json` の各職種に `background`(`/assets/img/escape-boss/bg/<職種ID>.svg`)。`scene.js` の `backgroundOf(job)` が、**決まった場所の SVG(小文字・数字・ハイフンの名前だけ)以外は、`null`** にする。`view.js` が、`--scene-bg`(CSS 変数)に `url("…")` を入れる。`null` なら、変数を外す(淡いグラデーションだけ) | データ由来の文字列を CSS に入れるので、引用符・かっこ・空白・上の階層(`..`)・外部の URL・ほかの形式を、通さない |
| 4 | CSS | `background-image: var(--scene-bg, none), linear-gradient(…)`(背景の絵を、淡いグラデーションの上に)。`background-repeat: repeat-x`・`background-position: left bottom`・`background-size: auto 100%`。場面の高さは、変えない(112px) | 主役(追ってくる人・自分)と、道は、そのまま |
| 5 | 読み込み | **プレイを始めたとき(連続タイピング)に、その職種の絵だけ**を読み込む。ダッシュボード・用語確認(場面がない)では、読み込まない。ゲームをやめて別の職種で始めると、背景が変わる | 通信・描画を、増やさない |
| 6 | 絵の安全 | 使うのは、装飾の図形(`svg`・`defs`・`g`・`rect`・`circle`・`ellipse`・`line`・`path`・`polygon`・`polyline`・`pattern`・`use`)だけ。**文字・画像・スクリプト・スタイル・動き・フィルタ・外部の参照は、使わない**。色は 16 進・`none`・同じ絵の中のパターンだけ。`href` は、同じ絵の中の `#id` だけ。テストが、要素・属性・色・参照先を、1 つずつ検査 | 将来、管理画面などから絵が入っても、安全に |
| 7 | 動きを減らす設定 | 背景は静止画なので、影響なし(追ってくる人の動きは、0028 のまま) | |
| 8 | 詳細ページ | ゲームを **0.13.0** に。更新履歴を追加。遊ぶ画面の画像(`play.webp`)を撮り直した(背景が写る) | 画面が変わった |
| 9 | 影響 | **ゲームの規則・距離・バランス・スコア・記録・語録は、変わらない** | 見た目だけ |
