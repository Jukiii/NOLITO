# 0069 キャラクターの絵を、現代風の立体的な絵に描き直す(Issue #166 PR 3)

## 理由

Issue #166 の運営者のコメント「もっと現代のゲーム感を出して欲しい / キャラクターがちゃっちい」を受け、ポップだが平面的だった 7 枚(あなた 2・追ってくる人 5)を、立体感のある絵に描き直した(運営者の選択: 「キャラ・演出を現代風に作り直す」)。

## 変更

- 絵 7 枚(`public/assets/img/escape-boss/`。ファイル名・viewBox・表示の大きさは、変えない): 肌・髪の放射/線形グラデーション、2 つのハイライトのある大きな目、ほお紅、2 色の手足とハイライト、足元の影(不透明度つきの楕円)。社長・会長は、金のグラデーションと輝きの図形。
- **絵の規則を緩めた(0030 を置き換える)**: 「図形だけ・13 色・4KB」→「図形とグラデーション(同じファイルの中の `url(#id)`)・16 進の色・8KB」。禁止は、文字・画像・スクリプト・スタイル・フィルタ・マスク・`clipPath`・`use`・`pattern`・動き・外部の参照のまま。安全面(スクリプト・外部参照なし)は、緩めていない。
- 場面に、上からの光と足元の床の影を重ねる(`game.css` の `.scene::before`。`tokens.css` に `--arcade-scene-light`・`--arcade-scene-shade`)。飾りで、動かない。
- 製品画面(`check.webp`・`play.webp`・`result.webp`)を撮り直した。

## 影響範囲

- 記録・ランキング・ゲームのロジック・HTML は変えない。距離・バランス・語録に影響なし。
- 絵のファイルは、1 枚 2.9〜5.8KB(上限 8KB)。

## テスト

- `tests/characters.test.js`(41 件): 要素・属性の許可リスト、色の形式、id の重なりと参照の定義、大きさの一致、顔の大きさ、グラデーション・足元の影、焦った顔の切り替え。
- Edge で、プレイ画面(1280px・360px・横向き 740×360・危ない状態・動きを減らす設定)を確認。横にはみ出しなし。
