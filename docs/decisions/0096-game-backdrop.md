# 0096 プレイ中の画面全体に追いかけ演出を加える(Issue #235)

## 理由

プレイ中の場面だけでなく、画面全体に「先輩に追いかけられる」演出を広げる。

## 決定

- プレイ画面(`data-view="play"`が表示中)だけ、画面全体の背景に先輩とプレイヤーの6コマ画像を大きく表示し、走るコマ送りを動かす。先輩は少しずつプレイヤーに近づく。ゲーム枠は透明、お題カードは半透明にして、追いかけっこがその背景にも見えるようにする。
- ネオンや格子を前提にしない。キャラクターの素材は既存の同一サイト内画像を使い、HTML・ゲームロジック・記録・音・ゲームの進行は変えない。
- 動きを減らす設定では、既存の全体ルールによりアニメーションを停止する。モバイルのレイアウトや入力操作には影響させない。

## テスト

- `tests/arcade-ui.test.js` で、追いかけ背景がプレイ中だけ適用され、6コマで動き、動きを減らす設定の抑制ルールが有効であることを検査する。
- `npm run test` と `npm run check` を実行する。
