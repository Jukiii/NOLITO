# 0074 スタート前の画面を、アーケード風にする(Issue #173)

## 理由

Issue #173「ここからゲーム感を出してほしい」の依頼。プレイ中・結果の画面は、Issue #166 でアーケード風(暗い枠・光る縁・ドット文字)にしたが、そこへ入る前の、スタート前の選択画面(モード・職種・追ってくる人・スタート)は、明るい普通のフォームのままで、ゲームらしさがなかった。

## 変更

- `game.css`: スタート前のフォーム(`.game-setup`)を、プレイ中・結果と同じ暗い枠(意味のあるトークンを、枠の中だけ暗い `--arcade-*` に置き換える共通の規則)に加えた。選択欄・ルールの箱・「くわしい設定」は、トークン経由なので、そのまま暗い色になる(読める明るさの比は、既存のトークンのテストが検査している)。見出しの文字(モード・職種・追ってくる人)はシアン、スタートのボタンは幅いっぱいの大きいボタンにした。
- `index.html`: フォームの先頭に、飾りの見出し `STAGE SELECT`(`aria-hidden`。自前の字体 `--font-display`。0070)を足した。日本語の案内・ラベル・ボタンの文字は変えていない。
- テスト: 共通の規則に `.game-setup` が入っていること、見出しが飾りであることを検査(`tests/arcade-start-result.test.js`・`tests/arcade-ui.test.js`)。

## 影響範囲

- 記録・ランキング・ゲームのロジック・語録・バランス・ポリシーの版は変えない。フォームの `data-*` の目印・操作の流れも同じ。
- 見た目だけの変更。見出しの `STAGE SELECT` は動かない(点滅・アニメーションなし)。幅 360px でも、横にはみ出さないことを確認した。

## 未対応

- 開始前の画面に、キャラクターの絵・場面を置くことはしていない(仕様にないため。希望があれば Issue #166 で扱う)。
