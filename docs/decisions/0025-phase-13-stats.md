# 0025 Phase 13 PR 3: 成績(連続ノーミス・難易度・速度・残り距離)と、記録の版 3

日付: 2026-09-21 / 対象: Phase 13「…成績に正解数・正確率・速度・難易度・連続正解・残り距離。…」。PR 1(0023)・PR 2(0024)の続きで、Phase 13 の最後の PR。

## 仕様と、現状の突き合わせ

| 仕様(成績に) | 状態 |
| ---- | ---- |
| 正解数・正確率・残り距離 | **済み**(結果画面・成績ページ) |

| **難易度** | **この PR**。打ち終えた語を、難易度ごとに数え、平均の難しさ・難易度別のミスを出す |
| **連続正解** | **この PR**。ミスなしで打ち終えた語の連続の最高(連続ノーミス) |

## 運営者が決めたこと(計画への「推奨案で」)

- **連続正解** = ミスなしで打ち終えた**語**の連続(正しい打鍵の連続(コンボ)ではない)
- **難易度**: 難易度別の語数を記録して、**平均の難しさ**と**難易度別のミス**を出す
- 成績ページは、表とまとめだけ(**グラフは足さない**)
- 保存は、**記録の版を 3** にする。移行のテストを厚くする

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 連続ノーミス | エンジン(`engine.js`)の状態に `streak`(いまの連続)・`bestStreak`(このプレイでの最高)・`wordMissed`(いまの語でミスしたか)を持たせる。**ミスした時点で、連続は 0 に戻り**、その語を打ち終えても連続には数えない(次の語から、また数える)。ゲームオーバーでも、それまでの最高が残る。**距離・時間・バランスは、変わらない**(`tests/balance.test.js` が、そのまま成功) | ミスなしで打ち終えた語だけが、連続。純粋なロジックのまま |
| 2 | 難易度ごとの語数 | 状態に `byDifficulty`({ "1": 3, "2": 5 })。打ち終えた語を、語録の難易度(整数の 1〜5)で数える。範囲外・整数でない値は数えない | 平均の難しさと、難易度別のミスの元データ |
| 3 | 保存(**版 3**) | 各結果に `streak`(0 以上の整数。**正解した語数を超えない**)・`wordsByDifficulty`(キーは `1`〜`5`、値は正の整数で 1000 まで)を追加。`DATA_VERSION` = **3**。**版 1・2 の結果は、読み込み時に自動で版 3 として扱い、この 2 つは `null`(記録なし。0 とは区別する)**。改ざんされた値(範囲外のキー・負・小数・文字列・配列など)は、捨てるか `null`。読み込んだだけでは、保存データを書き換えない。キー名の `v1` は変えない | 既存の記録を消さない。「記録なし」と「0」を分ける |
| 4 | 移行前の退避 | 版 2 から読むときは、元データを一度だけ `nolito:escape-boss:v1:backup-v2` に退避(上書きしない)。版 1 は、これまでどおり `:backup-v1`。**版 4 以上は、読まず、`:corrupt` に退避**(これまでの決まり)。退避に失敗しても、移行は続く | 移行の不具合に備える |
| 5 | 結果画面 | **入力速度**(打/分)・**最大連続ノーミス**(語)・**語の難しさ(平均)**を追加。正解・ミス・正確率・残り距離・時間は、これまでどおり | 仕様の項目を、そろえる |
| 6 | 成績ページ(まとめ) | **最大の連続ノーミス**・**平均の残り距離(クリアしたプレイ)**・**語の難しさの平均**を追加。記録のないもの(以前のプレイだけ・クリアなし)は「-」。期間・役職の絞り込みに従う | 以前のプレイを、0 として平均しない |
| 7 | 成績ページ(難易度別のミス) | 難易度(やさしい・ふつう・むずかしい)ごとの、**打った語数・ミスの回数・1 語あたりのミス**の表。難易度ごとの語数の記録があるプレイだけを使う(以前のプレイは、ミスも含めて除く。割合の分母をそろえるため)。ミスは、語ごとのミスの数(`wordMisses`)を、語録の難易度で振り分ける(語録にない語は、数えない)。「N 回分。以前のプレイには記録がありません」と伝える | 「どの難しさで、ミスしやすいか」がわかる |
| 8 | 成績ページ(最近のプレイ) | 列に「連続ノーミス」「残り距離(クリアのみ)」を追加。狭い画面では、表を横にスクロールする(最小の幅を決めて、文字が 1 字ずつ折り返されないように) | 見やすさ |
| 9 | グラフ | **足さない**(単位の違う指標は重ねない、という 0005 の方針。表とまとめで見せる) | 承認済み |
| 10 | スコア・ランキング・実績 | **変えない**(連続・難易度は、成績だけ。スコアの式・`records.js` に入れない。テストで検査) | 仕様にない。ランキングの尺度を変えない |
| 11 | 表示 | すべて `textContent`(`el()`・`setText`)。改ざんされた値は、文字として扱う | 安全 |
| 12 | 詳細ページ | ゲームを **0.10.0** に。FAQ「成績ページの『最大の連続ノーミス』『難易度別のミス』は、何ですか?」・更新履歴を追加 | 成績と記録が変わった |

## 保存形式の移行(版 2 → 3、版 1 → 3)

- 読み込み時に、版 1・2 の結果を、追加項目が `null`(記録なし)の版 3 として扱う。**以前のプレイの記録・ランキング・実績・プロフィール・進行状況・キーごとの集計・語ごとのミスは、そのまま**
- 集計では、`null` のプレイを、連続・難易度の対象から除く。0 として平均したり、「連続 0」と表示したりしない
- 次に保存するとき(プレイの結果の記録・設定ではなく、記録の更新)に、版 3 で書かれる。**読み込んだだけでは、書き換えない**
- **既知のリスク(0005 と同じ)**: 更新前のページ(古い JavaScript)を開きっぱなしのタブは、版 3 のデータを「壊れている」と扱う。そのタブで続けて遊ぶと、記録が初期化される(元の文字列は `:corrupt` に残る)。サイトを再読み込みすれば起きない。影響は、更新前から開きっぱなしのタブだけ

## 未確認・既知事項

- 実際の人間のプレイでの手ごたえは、未確認。以前のプレイには、連続・難易度の記録がないので、成績ページに、記録が貯まるまでは「-」が多い
- ミスの元データ(`wordMisses`)は、1 プレイで 60 語までしか残らない(0005)。1 プレイの語は 16 語以下なので、影響はない
- 難易度は、読みの長さで決まる(0006・0021)ので、「難易度別のミス」は、長い語のミスとほぼ同じ意味。人が難易度を付け直すとき(Phase 14 以降)に、意味が変わる
- スクリーンリーダーでの実機確認は未実施(見出し・表のキャプション・列見出しは、確認した)。Microsoft Edge(Windows・headless)だけで確認
