# 0094: 語録の増量 バッチ 2〜4 の公開

日付: 2026-10-04

## 背景

職種ごとに 300 語以上にする目標で追加したバッチ 2〜4 の語は、確認前の下書きとして保留していた。運営者が確認し、公開してよいと承認した。

## 決めたこと

- バッチ 2〜4 の 1,277 語を、すべて `review: confirmed` にして `draft` を外し、公開する。既存 ID は変えない。
- 6 職種の公開語録は、各 300 語・合計 1,800 語になる。既存の未確認語 203 語は、`review: pending` のまま維持する。
- ベース原稿の語録版を `0.7.0`、ゲームを `0.35.0` にし、ゲームの更新履歴を追加する。
- 語が長くなった影響をシミュレーションで確認し、役職ごとの `gain_per_char` を調整する。`tests/balance.test.js` の各 1,000 回のシミュレーションで、通常・やさしい・むずかしいのクリア率が既定の範囲に収まることを確認する。

## 影響・確認

- 役職ごとの `gain_per_char`: 先輩 `0.74`、係長 `0.58`、部長 `0.8`、社長 `0.75`、会長 `0.52`。
- 通常難易度のシミュレーションでは、遅い人の先輩クリア率が約 87%、普通の人の係長・部長・社長が約 90%・67%・49%、速い人の会長が約 76%。全役職で速い人ほどクリア率が下がらず、難易度別の検証も通過した。
- `npm run vocab:stats` のエラー・警告は 0 件。`npm run vocab:check` の類似語候補は、重複の断定ではなく人間の確認用の目安として残す。
- 公開 JSON・確認シート・ゲーム詳細ページは、それぞれ既存の生成コマンドで更新する。
