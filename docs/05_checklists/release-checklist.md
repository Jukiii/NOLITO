# リリースチェックリスト

公開の前後に、上から順に確認する。進め方(小機能単位の公開・戻し方)は `docs/release-process.md`、障害時は `docs/operations.md`、受け入れテストの中身は `docs/05_checklists/acceptance-test.md`。

## 公開の前(PR の中)

- [ ] 仕様と実装が一致(該当 Phase の仕様書・`docs/decisions/` を確認。仕様にない機能を足していない)
- [ ] 自動テスト成功: `npm run check`(lint・整形・単体テスト)
- [ ] 依存の脆弱性チェック成功: `npm run audit`
- [ ] 生成物が最新: `npm run build` のあと差分がない(記事・プロダクト詳細・語録)
- [ ] `migrations/` の変更があれば、`docs/auth-setup.md` の SQL も同じ内容で、**本番の D1 に実行済み**(PR の冒頭に書く)
- [ ] PC・スマホ・タブレット確認(下の「モバイル・環境の確認」)
- [ ] 主要ブラウザ確認(Edge・Chrome・Firefox・Safari。未確認のものは、PR とプロダクトの `requirements` に、そう書く)
- [ ] アクセシビリティ確認(キーボードだけで操作できる・フォーカスが見える・色だけに頼らない・動きを減らす設定・ダーク/ライト)
- [ ] パフォーマンス確認(画像は SVG か遅延読み込み・不要な通信がない・キャッシュの設定は `public/_headers`)
- [ ] 秘密情報・個人情報・DB のバックアップを、コミットに含めていない(`git status`・差分を確認)
- [ ] プライバシー・規約・広告表示確認(取り扱いを変えたなら、ポリシーの版を上げて履歴に足した。広告は `/ads-policy/` と一致)
- [ ] 更新履歴を書いた(プロダクトを変えたなら、`version` と `changelog`)

## マージ直前

- [ ] CI が成功し、PR ブランチの Cloudflare プレビューを確認した
- [ ] 今回の変更内容と確認済みプレビュー URL をまとめたコメントを PR に投稿した(URL が確認できない場合は、その旨を記載)

## モバイル・環境の確認

- [ ] 幅 360px 前後・タブレット・PC で、横にはみ出さない・文字が読める
- [ ] タッチで、全面をタップして操作できる(小さい当たり判定・ホバーだけの機能がない)
- [ ] ゲーム: ソフトウェアキーボードを開いても、入力欄が隠れない。縦・横の向きを変えても遊べる
- [ ] 文字サイズ「特大」・ダークテーマ・「動きを減らす」で、崩れない
- [ ] 本物のブラウザで確認できない点(音色・実機のキーボードなど)は、確認できていないと、PR に書く

## 公開の後

- [ ] 公開したサイトで、簡易チェック: `npm run smoke -- <URL>`(主要ページ・API・404・同意前に Google へ通信しないこと)
- [ ] 主要なページを、目で確認(トップ・ゲーム・記事・アカウント)
- [ ] エラー監視・復旧手順の確認: 何かあれば `docs/operations.md`(止める → 戻す → 確認 → 記録)
- [ ] ブランチは削除しない

## 戻せる状態か(ロールバック)

- [ ] サイト: Cloudflare → Pages → Deployments → 以前の本番デプロイ → **Rollback**、または PR の **Revert**(新しい PR として。`main` に直接コミットしない)
- [ ] データベース: 大きな変更の前に `npm run backup:d1`(`docs/backup.md`)。直近 7 日の間違いは D1 Time Travel。**サイトのロールバックでは、データベースは戻らない**
- [ ] 緊急停止: `AUTH_ENABLED`・`CONTACT_ENABLED` を `false` にして再デプロイ
- [ ] 記録の形(LocalStorage)を変えたなら、古い版を読める(利用者の記録を消さない)
