# 0061: スタート前の選択の並びと、難易度 = 追ってくる人(Issue #144)

## 背景

運営者からの依頼(Issue #144)。

1. 難易度と、追ってくる人(役職)は、同じ意味。難易度の選択は要らない。
2. モードの選択は、ラジオボタンにする。
3. 並びは「モード」「職種・追ってくる人」「スタート」にする。

## 決定

- **開始前の選択から、難易度の選択欄をなくした**。プレイは、いつも既定の難易度(ふつう = `DEFAULT_DIFFICULTY`)。難しさは、追ってくる人(役職)で選ぶ(役職が上がるほど、むずかしい)。役職の欄の見出しに、その意味を添えた(「追ってくる人(役職が上がるほど、むずかしい)」)。
- **モードは、ラジオボタン**(`data-mode-list`。連続タイピング・用語確認)。職種・追ってくる人は、これまでどおりドロップダウン。
- **並び**: モード → 職種・追ってくる人(広い画面は横 2 列、狭い画面は縦)→ 役職のルール・自己ベスト → スタート → 「くわしい設定」。用語確認では、追ってくる人・ルールを隠す。
- 自己ベストは、選んだ職種・役職の「ふつう」のもの(`updateBest`)。
- **残したもの**(変えない): 難易度のデータ(`difficulties.json`)・`beginGame` の難易度の解決・`applyDifficulty`・記録の形と版(5)・オンラインの / 端末内のランキングの難易度の選択欄・成績ページの難易度の集計・`lastChoice.difficulty`(保存された値が残っていても、使わない)。過去にやさしい・むずかしいで遊んだ記録は、これまでどおり読める。
- プライバシーポリシーの版は、上げない(端末内の表示の変更だけ)。

## 影響範囲

- 利用者: スタート画面から「やさしい」「むずかしい」を選べなくなった。むずかしい系の挑戦(ふつうでクリアすると解放)は、いまの画面からは始められない。**復活させるか、難易度を役職に統合し切るかは、運営者の判断**(別の Issue で確認する)。
- 記録・ランキング・実績・D1・環境変数: 変更なし。
- ゲームの版: 0.29.0(`products.json` の `changelog`)。

## 既知の制限

- ゲームの紹介用スクリーンショット(`public/assets/img/products/escape-boss/`)は、撮り直していない。
- ランキングの難易度の選択欄(端末内・オンライン)は、そのまま。むずかしいの記録がない人には、空の表が出る。
- 375px 幅で、スタートのボタンが、画面の下の固定バーに重なる位置に来ることがある(スクロールすれば押せる)。
