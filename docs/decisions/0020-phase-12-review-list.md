# 0020 Phase 12 PR 2: 復習リスト

日付: 2026-09-21 / 対象: Phase 12「復習リスト対応」。PR 1(0019: 用語確認モード・説明の表示)の続き。

## 運営者が決めたこと(計画への「推奨案で」)

- **範囲**: 直近 **20 プレイ**でミスした語を、ミスの多い順に、**最大 20 語**
- **用語確認の結果は、保存しない**(復習リストの元データにならない)。保存の形(`DATA_VERSION` 2)は、変えない

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 元データ | 各プレイの結果に保存済みの **語ごとのミス数(`wordMisses`)**(Phase 4 から)。**新しく保存するものは、ない**。記録の版・形・キーは、変えない | 既存の記録が、そのまま使える。移行が要らない |
| 2 | 集め方(`review.js`。DOM に依存しない純粋な関数) | 記録の先頭(新しい順)から **20 プレイ**を見て、語ごとに、ミスの数を合計する。**役職・職種は問わない**。並び順は、ミスの合計の多い順 → 最近ミスした順 → id 順(毎回、同じ結果)。上位 **20 語** | 承認済みの範囲 |
| 3 | 語録の変更に強くする | 語録に**見つからない語**(id が消えた・別のデータ)・ミスの数が 0・負・小数・数でない値は、**無視する**。`wordMisses` がない以前の版の記録・`results` が空でも、落ちない | 語録を直しても、既存の記録で、落ちない(語の id は、消さない・つけ替えない方針) |
| 4 | 成績ページ | 「復習リスト」の節を、**期間・役職の絞り込みより上**に置く(絞り込みの影響を受けない旨を、説明に書く)。1 件ずつ、日本語・読み・**職種**・**ミスの回数**・説明。語がなければ「復習する語は、まだありません。連続タイピングでミスすると、ここに出ます。」で、一覧とボタンを出さない。記録が 1 件もなければ、これまでどおり「まだ記録がありません」だけ | 絞り込みで、リストが変わると、わかりにくい |
| 5 | 用語確認への入り口 | 「復習リストで用語確認をする(N語)」のリンク → ゲームのページ `/games/escape-boss/?review=1` → **その場で、復習リストの語だけの用語確認が始まる**(アドレスから `?review=1` を消す)。語の順は、**混ぜる**(ミスの多い順のままだと、順番を覚えてしまう)。語数は N 語(最大 20)。「職種」の欄は「復習リスト」。用語確認と同じく、結果は**保存しない** | 用語確認(0019)の仕組みを、そのまま使う |
| 6 | 復習する語がないとき | `?review=1` で来ても、ダッシュボードのまま、案内(`role="alert"`)を出す | 空の用語確認を始めない |
| 7 | 再挑戦 | 復習リストの用語確認の結果の「もう一度」は、復習リストで、また始まる(記録を読み直す) | 職種の用語確認と、同じ操作 |
| 8 | 部品の共通化 | 一覧の 1 件の描画は `review-item.js`(結果の画面と成績ページで共通)。語録の文字列は、`el()`(textContent)だけで入れる | 二重に持たない。安全な表示を、1 か所に |
| 9 | ダッシュボード | 成績ページへのリンクの文言を「成績・成長グラフ・苦手文字・復習リストを見る」に | 見つけやすく |
| 10 | 詳細ページ | ゲームを **0.5.0** に。更新履歴・FAQ(用語確認・復習リスト)を更新。画面(ダッシュボード)を撮り直した | 画面が変わった |

## 見つけたこと

- **Phase 4 の確認スクリプトの 1 件(タブレットでグラフをタップ)が、失敗するようになった**: 復習リストの節が増えて、グラフが画面(高さ 1024px)の下に押し下げられ、スクリプトが**スクロールせず**、座標でタップしていたため。グラフを画面内にスクロールしてからタップすると、84/84 成功。実際の操作(利用者は、スクロールしてグラフに触れる)の不具合ではなく、スクリプトの限界(リポジトリには、入れていない)
- テストの誤り(実装の不具合ではない): 確認スクリプトの「見える」判定が、親要素の非表示を見ていなかった

## 未確認・既知事項

- スクリーンリーダーでの、実際の読み上げは、未確認(見出し・リンク・案内の `role="alert"` は確認した)。Microsoft Edge(Windows・headless)だけで確認
- 復習リストは、**連続タイピングの記録だけ**が元(用語確認は保存しない)。用語確認で覚えても、リストから消えるのは、連続タイピングをまた遊んで、直近 20 プレイの範囲から外れたとき
- 語録の語の id を、消す・つけ替えると、その語は、復習リストから消える(Phase 11 の PR 2 の方針: id は、消さない)
