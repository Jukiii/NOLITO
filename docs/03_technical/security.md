# セキュリティ

最終更新: Phase 30(2026-09-30)。方針と、実際にコードで守っていることの対応表。守っている性質の多くは、`tests/` の自動テストで検査している。

| 方針 | 実際の対応 | 詳しくは |
| ---- | ---------- | -------- |
| 最小権限 | 管理者は環境変数 `ADMIN_EMAILS`(DB にフラグを持たない)。招待制(`SIGNUP_MODE=invite`)。Google のスコープは `openid email` だけ | 0013・0051 |
| サーバー側の権限チェック | 書き込みの API は `requireUser`/`requireAdmin`(`{ write: true }`)。GET で状態を変えない。画面の出し分けは見た目だけ | `functions/_lib/guard.js` |
| 入力値の検証・出力のエスケープ | 検証は、公開の JSON と同じ `schema.js` を、サーバーも共有する。表示は `textContent`(`el()`)だけ。URL は `/` 始まりか `https://` だけ。記事の生の HTML は文字にする | CLAUDE.md |
| CSRF | 状態を変える API は、Origin の一致 + `X-NOLITO-CSRF` + JSON(`checkCsrf`) | 0013 |
| セッション・Cookie | DB にはハッシュだけ。`__Host-`・`Secure`・`HttpOnly`・`SameSite=Lax`。JS から Cookie を読まない | 0013 |
| ログイン | 認可コード + PKCE + state + nonce。ID トークンは RS256 だけを、署名・`iss`・`aud`・`exp`・`nonce`・`email_verified` まで検証。ブラウザに Google のスクリプトを読み込まない | `functions/_lib/google.js` |
| 秘密情報を Git に置かない | シークレットは Cloudflare の環境変数だけ。`.dev.vars`・DB のバックアップは Git に入れない(`.gitignore`)。本物の D1 の ID もコミットしない | 0015 |
| 再認証 | 取り消せない操作(アカウント削除・管理 API の削除)は、直近 10 分以内のログインだけ(`recent: true`) | 0052 |
| 監査ログ | 出来事ログ(`audit_log`)と、管理の変更の前後(`admin_audit_log`)。メールアドレス・IPv4 は書き込みの入り口で自動的に伏せる。180 日で削除 | 0051・0052 |
| 回数の制限 | ログイン・ライセンス登録・問い合わせ・同期・ランキングなど。キーにメールアドレス・IP をそのまま入れない | `functions/_lib/` |
| ライセンスキー | 100 ビットの乱数。DB にはハッシュと末尾 4 文字だけ。存在の有無を探れない同じ応答 | 0014 |
| バックアップの暗号化・復元テスト | 手元の書き出し(直近 6 か月・古いものの整理 `backup:prune`)+ D1 Time Travel(7 日)。`backup:restore-drill` で、使い捨ての D1 に実際に復元して確かめる。**暗号化は、まだ行っていない**(下記) | `docs/backup.md`・0015・0052 |
| 依存関係の更新・脆弱性チェック | `npm run audit`(high 以上で CI が止まる)。Dependabot が、毎週、npm と GitHub Actions を確認(マイナー・パッチは 1 つの PR にまとめる) | 0052 |
| 個人情報・削除要求 | アカウント削除で、ゲーム記録・設定・ランキングの行が消える(ライセンスは結びつきだけを外す)。問い合わせは、ログインと結びつけない。プライバシーポリシーは版管理し、取り扱いを変えたら版を上げて同意を取り直す | `/privacy/`・0040 |
| 広告関連の表示 | `/ads-policy/`。「PR」「広告」の文字表示(`kind` から決まり、データで書き換えられない)・報酬の明記・`rel="sponsored noopener noreferrer"`。広告事業者のスクリプトは、まだ入れない | 0054 |
| 外部への通信 | Google アクセス解析は、同意するまで何も要求しない。音・画像は、ファイルなし(Web Audio 合成・SVG)。外部の監視・通知サービスは入れていない | 0032・0053 |

## 既知の未対応(区切りとしたもの)

- **バックアップの暗号化**・**多要素認証(MFA)**: 運営者が 1 人で、保管先も手元だけのため、着手していない。複数の運営者・外部保管を始めるときに、範囲を決める(0052)。
- **有料 API・外部の監視サービス**: 規約・費用・第三者への送信・ポリシーへの影響を確認してから(CLAUDE.md の作業ルール 7)。

## 脆弱性を見つけたら

公開の場(Issue など)に、再現の手順を書かず、`/support/` の問い合わせから連絡する。
