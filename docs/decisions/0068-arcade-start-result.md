# 0068: 開始画面の点滅と、結果画面のドラムロール(Issue #166 PR 2)

## 背景

Issue #166(アーケードゲーム風の画面)の 2 つ目の PR。0067(PR 1)の続き。「PRESS SPACE KEY TO START」の点滅と、結果画面(暗い枠・数が増えるスコア)を作る。ドット文字は PR 3。

## 決定

- **開始の点滅**: 準備の枠(`data-ready`)に、飾りの 1 行「PRESS SPACE KEY TO START」(`aria-hidden`)を足す。日本語の案内(テスト・読み上げが使う)は、そのまま残す。点滅は不透明度だけ、1 周 1.2 秒(0.8 秒以上)。`@keyframes` の 100% が「見える状態」なので、動きを減らす設定(1 周 0.01ms・1 回)では、見えたまま止まる。
- **結果の画面**: `.game-result` を、`.game-play` と同じ暗い枠・トークンの再定義にする(共通のブロック + `.game-play` だけのレイアウト)。見出しは黄色、「RESULT」の飾り(`aria-hidden`)、スコアは光る等幅の数字。用語確認の結果も、同じ枠。
- **ドラムロール**(`countup.js`。DOM・時計に触れない純粋なロジック。`ROLL_MS` = 1.6 秒・減速): 本当のスコア(`data-result-score`)は、**いつも DOM にある**(最初から値が入っている)。数えている間だけ、`aria-hidden` の別の欄(`data-result-roll`)を見せ、本当のスコアは `visually-hidden` にする。読み上げは、最後の値だけを読む。終わる・飛ばすと、欄を隠して、本当のスコアを見せる。
- **飛ばし方**: 結果の画面のクリック、または Enter・スペース・Esc(フォーカスが見出し `[data-result-title]` か `body` にあるときだけ)。ボタン・リンクのキーは奪わない。
- **動きを減らす設定**(`prefersReducedMotion()`。サイトの設定か OS の設定): 数えずに、最初から最後の値を見せる。
- 結果の保存・実績・経験値・ランキングの送信は、これまでどおり、結果を出す前に済んでいる。ドラムロールは、見た目だけ。
