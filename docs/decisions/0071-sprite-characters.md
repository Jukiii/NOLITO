# 0071 キャラクターを、6 コマのコマ送りの絵にする・入力欄を画面から隠す(Issue #166 PR 5)

## 理由

Issue #166 の運営者のコメント「そもそもキャラクターのデザインが嫌や / もっとキャラクターをこって作って欲しい / リアルなキャラクターにして / キャラクターが揺れてるだけで動いてない / 入力欄がまだ表示されてる」を受けた。

## 変更

- **キャラクターの絵(7 枚)を、6 コマのスプライトシート(横に 6 コマ並べた SVG)にした**。追ってくる人 5 枚は 720×80(1 コマ 120×80)、あなた 2 枚(ふつう・焦った顔)は 384×80(1 コマ 64×80)。各コマは `<g transform="translate(コマの幅×番号 0)">` で包む。絵は、頭身を上げ、体の比率・服のしわ・髪・影を描き込んだ、よりリアルな描き方。乗り物の種類(自転車・車など)は変えない。
- 画面は、**枠(`.scene__chaser-img` / `.scene__player`。`overflow: hidden`。従来の動き・演出・合図・焦った顔の切り替えは、この枠が持つ)の中に、6 倍の幅(`width: 600%`)の `<img class="scene__sprite">`** を置き、`sprite-frames`(`translateX(0 → -100%)`)を `steps(6) infinite` で回して、コマを送る。コマ送りの速さは `--sprite-cycle`(役職の動きごと。焦った顔は 0.4 秒)。
- **動きを減らす設定では、コマ送りは止まり、1 コマ目の静止画になる**(`base.css` の全体の規則)。従来の「揺れるだけ」の動き(`scene-bob`)は、コマ送りに置き換えた。走る・こぐの上下の動きだけ、残す。
- **絵の規則の追加の緩和(0069 を更新)**: 1 枚 8KB → **40KB**(6 コマ分)。「顔の円(`url(#sk)`)の直径が高さの 25% 以上」は、シートの構造に合わないため、**肌のグラデーション `url(#sk)` を使うこと**に置き換えた。ほかの規則(許可する要素・色の形式・フィルタなどの禁止・足元の影・グラデーション 2 つ以上)は、そのまま。6 コマが「おおむね違う絵」(動いて見える)ことと、6 つの枠があることを検査する。
- **入力欄(`#game-input`)を、画面から隠した**(1px に切り抜く。`display: none`・`visibility: hidden` は使わない = フォーカスと、ソフトウェアキーボードを保つ)。ラベルは、読み上げ用に残す。打った文字は、単語の上の色分け(`data-word-typed` / `data-word-rest`)で、すでに見える。**単語のカードを押すと、入力欄にフォーカスする**(スマホで、キーボードを出し直せるように)。ミスの文・IME の案内は、そのまま表示。

## 影響範囲

- 記録・ランキング・ゲームのロジック・バランス・語録は変えない。HTML は、キャラクターの 3 枚の構造と、フォーカスの案内の文だけ変えた。
- 絵のファイル名・場所は変えない。**表示の大きさは、絵の細部が見えるよう、大きくした**(`game.css` の `--chaser-w`・`--player-w`・`--scene-h`。広い画面: 12 → 15rem・6.4 → 8rem・13 → 15.5rem、狭い画面: 7.5 → 8.5rem・4 → 4.8rem・9.5 → 10.5rem)。360px で横にはみ出さないことを確認した。

## テスト

- `tests/sprite-scene.test.js`(新規): コマ送りの CSS・HTML の構造、入力欄の隠し方(`display: none` を使わない)、単語カードのクリック。
- `tests/characters.test.js`: 6 コマ・40KB・肌のグラデーション。`tests/scene.test.js`・`tests/rule-cues.test.js`: 構造の検査を、枠 + 絵の形に更新。
- Edge で、1280px・360px・横向き・動きを減らす設定・危ない状態を確認。

## 未対応

- 絵の細かい好みは、運営者の確認待ち(コマ数・サイズ・リアルさの度合い)。
