# 0078: 語録の増量 バッチ 1(Issue #182)

日付: 2026-10-03

## 背景

Jさんの依頼(Issue #182): 「タイピングゲームの言葉の数が少なすぎる」「語録がそれぞれ 300 単語以上」。進め方は「お任せで」(2026-10-03)。

## 決めたこと

- 目標は、職種ごとに 300 語以上。一度には作らず、**1 バッチ = 職種ごとに約 50 語**で積み上げる。
- バッチ 1 は、拡張ファイル `content/vocabulary/<職種ID>.ext-batch1.md` に、**すべて `draft: true` / `review: pending` の下書き**として置く(計 320 語。エンジニア 54・営業 49・事務 56・飲食 52・講師・教育 56・接客販売 53)。**公開の JSON には入らない**(公開は 203 語のまま)。
- 人間の確認ルール(0026)は、そのまま。Jさんが「OK」と言った語だけ、`draft` の行を消して公開する。確認済み(`confirmed`)にするのも、Jさんの判断。
- 会社・地域・ツールで意味が違いうる語(スプリント・与信・月次処理・福利厚生・お通し・通知表・不登校・レジ締め)は、`note` で確認を求める。
- 既存の語の id・内容は、変えていない。バッチ 1 の id は、各職種の最後の番号の続きから振った。

## 影響

- 公開する語数・クリア率は、いまは変わらない(下書きは公開されない)。**公開するときに**、`tests/balance.test.js` のシミュレーションで、クリア率の階段(0006・0021)を確認する。
- 下書きの語が増えたため、`tests/vocab-build.test.js` の「下書き 0 語」「note 41 件」「警告 2 件」などの、決め打ちの数を、実際の原稿に合わせた(下書きの数は、数字に依存しない形にした)。
- `npm run vocab:check` の類似語の警告は 13 件(並ぶ概念・対になる語が多い。目安であり、重複とは限らない)。同じ意味の語は、事前に除いた(例: キッチン。厨房と同じ説明になるため)。

Jさんの確認 → 公開 → 次のバッチ(300 語に届くまで)。
