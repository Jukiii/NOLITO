# 受け入れテスト

「利用者の目で、主要な機能が使えるか」の確認項目。自動テスト(`npm run check`)が守るのは、ロジックと決まった性質。**実ブラウザ・実機でしか確かめられないもの**を、ここで人が確かめる。公開のたびに、変更に関わる節だけ行えばよい(全体は、大きな公開の前)。結果は PR に書く。

## 1. サイト全体

- [ ] 主要ページ(トップ・ゲーム・ツール・ソフト・記事・検索・更新履歴・サポート・プライバシー・利用規約・広告・収益化)が開ける
- [ ] ヘッダー(PC の開閉メニュー・モバイルのハンバーガー・下部の固定バー)・フッターのリンクが、行き先どおり
- [ ] テーマ・文字サイズ・アニメーションを切り替えられ、再読み込みしても保たれる(ちらつかない)
- [ ] 検索で、プロダクト・記事・用語が見つかり、絞り込みができる
- [ ] 初回アクセスで同意のバナーが出て、**同意するまで Google に通信しない**(ブラウザの開発者ツールのネットワークで確認)
- [ ] 存在しないページで 404 が出る

## 2. ゲーム「上司から逃げろ」

- [ ] 職種・役職・難易度を選べる。ロック中の役職・難易度は選べず、理由が分かる
- [ ] 連続タイピング: 正解で距離が増え、ミス・時間で減る。危ないとき、場面・文字の合図が出る。終わると、結果(スコア・正確さ・今回出てきた語すべての説明・経験値)が出る
- [ ] 用語確認: 追いかけなし・時間制限なし。結果は保存されない
- [ ] 入力方式(標準・訓令式・表示どおりだけ)が効く。IME がオンでも、判定が崩れない
- [ ] 演出(開始・終わり)を、Enter・スペース・Esc・クリックで飛ばせる。「動きを減らす」で短くなる
- [ ] 音は既定でなし。設定すると鳴り、なしに戻すと止まる(音色・音量は、耳で確かめる)
- [ ] 成績ページ: グラフ・表・復習リスト・熟練度・ハイスコアが出る。復習リストから用語確認が始まる
- [ ] 記録の書き出し・読み込み(確認のダイアログを経由し、押すまで置き換わらない)
- [ ] スマホ: ソフトウェアキーボードで入力できる。横向きでも遊べる

## 3. ツール「キーみち」

- [ ] アプリ・操作の登録・ルートへの並べ替え・チートシート(印刷・Markdown)・JSON の書き出し/読み込み
- [ ] 「キーを押して入力」から、Esc・別の場所のクリックで抜けられる(キーボードトラップがない)
- [ ] 練習モード: 答えの枠でだけキーを受け取り、Tab で移動できる

## 4. アカウント(設定がそろった環境だけ)

- [ ] 許可リストのアカウントで、Google ログイン・ログアウトができる。許可リストにないアカウントは、作られない
- [ ] ゲームの記録・表示設定の同期(アップロードは即時、ダウンロードは確認ダイアログ経由)
- [ ] オンラインランキング: 既定は不参加。参加・不参加の切り替えで、公開・非公開になる
- [ ] ライセンスの登録(存在しない・使用済みは同じ応答)
- [ ] アカウント削除は、直近 10 分のログインだけ。それ以外は、再ログインを求める
- [ ] 設定のない環境(プレビュー)で、アカウント・問い合わせが「準備中」になり、壊れない

## 5. 問い合わせ・記事・プロダクト

- [ ] 問い合わせを送れる(保存のみ。メールは送らない)。ボット対策の欄は、見えない
- [ ] 記事の一覧・詳細・目次・関連が出る。危険なリンクは、ビルドで失敗する
- [ ] プロダクトの一覧・詳細ページ・更新履歴が出る。外部リンクに移動の注意がある

## 6. 管理画面(管理者だけ)

- [ ] `/account/admin/products/`・`/account/admin/affiliates/`: 一覧・作成・編集・削除ができる。管理者でない人・未ログインは、見られない
- [ ] 不正な内容は、検証エラーの一覧が出て、保存されない
- [ ] 削除は、直近のログインが必要(古ければ、再ログインの案内)
- [ ] 変更が、監査ログに残る(D1 の `admin_audit_log`。メールアドレス・IP が入っていない)

## 7. 広告・収益化

- [ ] いまは、どのページにも広告・アフィリエイトが出ない(`config/ads.js` の `enabled: false`)
- [ ] 有効にする前: `/ads-policy/`・プライバシーポリシー §5 の記載が実態と一致。「PR」「広告」の文字・報酬の説明・外部サイトの注意が出る。**プレイ画面には出ない**
