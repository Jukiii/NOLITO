# 0059: ゲームのスタートまでの操作(Issue #140)

## 背景

運営者からの依頼(Issue #140。急ぎ)。

1. 連続タイピングは、スタートを押すと、すぐに始まっていた。スペースキーを押して始めたい。日本語入力(IME)がオンで、全角のスペースが入ったときは、始めずに、全角だと知らせたい。
2. スタートの前に出る設定が多い。ドロップダウンにまとめ、前回の設定を引き継ぎたい。

## 決定

- **進み方は `ready → intro → play → outro → 結果`**。「スタート」を押す(`beginGame`)と、`session.phase = "ready"` になり、準備の枠(`data-ready`)が出る。ここでは、時間が進まず、入力もミスに数えない。
  - **半角スペース**を入力すると、`leaveReady()` → `beginIntro()`(0031 の開始の演出)へ進む。
  - **全角スペース(U+3000)**は、始めず、枠の中に「全角のスペースが入力されました…」と出す(`role="alert"`。色だけでなく、文字と破線の枠で示す)。
  - それ以外の文字は、何もしない(ミスにも数えない)。
  - 「スタート(タップでも始められます)」のボタンでも始められる(スマホ・スペースキーのない環境のため)。
- 判断は `ready.js` の `readyAction(char)`(DOM・時計に触れない純粋な関数)。全角スペースは、ソースに直接書かず `String.fromCodePoint(0x3000)`。入力は、これまでどおり `input.js` の `input` イベント(IME の変換中は無視)から `handleChar` に来て、`phase === "ready"` のとき `handleReadyChar` に渡す。
- **`beginIntro` を呼ぶのは `leaveReady` だけ**。用語確認(check モード)には、準備も演出もない(従来どおり、すぐに始まる)。準備の枠は、`data-chase-only` を付けない(`showPlay` が、その印の要素を再表示するため)。
- **設定の整理**: モード・職種・追ってくる人・難易度を、ラジオボタンから、**ドロップダウン(`<select>`)**にした。ロック中の選択肢(会長・むずかしい)は、`disabled` にして、文字のバッジ「[ロック中]」で示す。そのほかの設定(説明・演出・苦手な語・ローマ字・音)は、ダッシュボードの `<details class="game-setup__more">`「くわしい設定」に畳んだ(ダッシュボードの開閉は、プレイ画面ではないので、0027 の「プレイ中に開閉の部品を置かない」に反しない)。
- **前回の選択の引き継ぎ**: ゲーム設定(`nolito:escape-boss:settings:v1`。記録のキーとは別)に `lastChoice`(`mode`・`job`・`role`・`difficulty`。それぞれ `^[a-z0-9-]{1,30}$` だけ。壊れた値は空に戻す)を足した。選択を変えるたびに保存する。読み込み時、いまは選べない値(消えた職種・ロック中の役職など)は、選ばずに、既定の状態にする。**記録(`nolito:escape-boss:v1`)の形・版(5)は変えない**。
- **プライバシーポリシーの版は、上げない**(端末内の設定の保存で、サーバーに送らない。0032 の音の設定と同じ判断)。

## 影響範囲

- 利用者: スタートのあと、スペースキー(かボタン)を押すまで、始まらない。設定は、上の 4 つのドロップダウンだけが見え、残りは「くわしい設定」の中。
- 記録・ランキング・実績・D1・環境変数: 変更なし。
- ゲームの版: 0.28.0(`products.json` の `changelog`)。

## 既知の制限

- ゲームの画面(`public/assets/img/products/escape-boss/`)の紹介用スクリーンショットは、撮り直していない(運営者の確認のあと、別に行う)。
- 全角スペースの判定は、ブラウザが `input` イベントで `U+3000` を渡す場合に限る。IME が変換中の状態にしたままの入力は、確定するまで無視される(0027 以前からの、IME の扱いのまま)。
- `/games/escape-boss/` は、375px 幅で、わずかに横にあふれる(0058 に記載。以前からある)。

## テスト結果

- `npm run check`(2183 件)・`npm run audit` 通過。`tests/game-ready.test.js`(準備の判断・配線・`lastChoice` の正規化)を新設。既存の配線テストは、ドロップダウン・「くわしい設定」の構造に合わせて更新した。
- ヘッドレスの Edge で、次を確認した: 自動では始まらない・文字キーは無視・全角スペースで通知が出て始まらない・半角スペースで演出が始まる・ボタンで始まる・再読み込みで前回の選択が残る・用語確認には準備がない・375px 幅の表示。
