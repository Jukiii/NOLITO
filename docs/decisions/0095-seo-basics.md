# 0095: 検索エンジン向けの基本情報

日付: 2026-10-04 / 対象: Issue #227

## 背景

Phase 5 の決定(0007)では、仕様にない `sitemap.xml`・`robots.txt` を対象外としていた。Issue #227 の「SEO対策」の依頼を受け、外部サービスや有料APIを使わず、検索エンジンが公開ページを発見し、正規URLを判別できる基本情報を追加する。

## 決定

- `/robots.txt` はサイト全体のクロールを許可し、`/sitemap.xml` のURLを案内する。
- `/sitemap.xml` は検索に載せる公開ページの固定パスと、公開中の記事を返す。記事は D1 があれば公開記事だけを読み、D1 がない環境では `public/data/articles.json` を使う。
- アカウント・管理画面・プレイヤー記録・スタイルガイド・デザイン見本・静的な記事の写しは、サイトマップに含めない。既存の `noindex` と `X-Robots-Tag` は維持する。
- 正規URLが未設定だった公開ページに canonical を追加する。新しい公開ページを sitemap に加えたときは、canonical と description も確認する。
- 検索順位や登録を保証するものではない。構造化データ、外部SEOサービス、広告計測の変更は行わない。

## 影響・検証

- 検索クローラー向けのテキスト・XMLと公開ページの `<head>` のみを変更する。利用者のデータ、計測、外部通信には影響しない。
- テストでサイトマップの公開記事限定・非公開ページ除外・D1なし時のフォールバック、robots.txt、および公開ページの canonical を確認する。
