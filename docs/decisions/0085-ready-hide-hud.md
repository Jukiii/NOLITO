# 0085: 準備の画面では、ステータス・ゲージ・場面を出さない(Issue #173)

日付: 2026-10-03

## 経緯

準備の画面(0059・0084)に、あなたのキャラクターと吹き出しを出したあと、Jさんが、Issue #173 で、スクリーンショットを付けて「ここのぶぶんも待機画面でいらない」と答えた。画像の部分は、ステータスの行(職種・追ってくる人・正解・ミス)・距離のゲージ・場面(追ってくる人とあなたの絵)。

## 変えたこと

- 準備の間(`view.showReady` から `hideReady` まで)、`[data-play]` に `data-ready-state="on"` を付ける。`game.css` が、この印があるとき、`.game-status`・`.gauge-block`・`.scene` を隠す(`display: none`)。
- 準備の枠(キャラクター・吹き出し・PRESS SPACE KEY TO START・スタートのボタン)と、「音」「やめる」は、残す。
- `hidden` 属性は使わない(用語確認で隠す `data-chase-only` の `hidden` と、取り合わないため)。始まる(`leaveReady`)・やめる・新しいゲームのたびに、`hideReady` が印を外す。

## 変えないこと

- ゲームの進み方(ready → intro → play → outro → 結果)・保存・記録の形・語録・バランス。

## テスト

- `tests/game-ready.test.js` に、印の付け外しと、CSS が隠す対象(「音」「やめる」は隠さない)を検査するテストを足した。`npm run check` は通っている。幅 1200px と 360px で、準備の画面を、ブラウザで確認した(横にはみ出さない)。
