# 0098: 開発コマンド・コードキーワードを英語で入力できるようにする(Issue #238)

日付: 2026-10-07

## 背景

運営者から、カタカナ表記になっている「英語で普段入力する」語を見直す依頼があった。対象の語は指定されなかったため、全職種の語録を、決定 0056 の「識別子・コマンドとして、英字のまま打つ」基準で確認した。

## 決めたこと

- エンジニアの `build`・`deploy` は開発で入力するコマンド名、`merge`・`push`・`clone`・`checkout` は Git のコマンド、`import`・`export` はコードに書くキーワードなので、日本語表記を英語にし、`typing` を設定する。読み・語 ID・難易度は変えない。
- ほかのカタカナ語は、会話で使う用語・概念の名前であり、コマンドや識別子としてそのまま入力する語ではないため変更しない。たとえば `server`・`cloud`・`database`・`refactoring` は、決定 0056 の対象外のままにする。
- 語録の版を `0.9.0`、ゲームの版を `0.37.0` にし、公開 JSON とゲームの更新履歴を更新する。記録の形式・版は変えない。

## 影響・確認

- この見直しで英語入力にしたのは、エンジニアの8語(build・deploy・merge・push・clone・checkout・import・export)。ほか5職種の語録、ゲームの記録・ランキング、役職の設定は変えない。
- `tests/input-style.test.js` で8語の英語表記・入力文字列を検査し、既存の全語入力テストで各方式の入力と距離計算への影響を確認する。
