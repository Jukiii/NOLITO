# 0024 Phase 13 PR 2: 入力方式設定(ローマ字の書き方)

日付: 2026-09-21 / 対象: Phase 13「…複数ローマ字表記と入力方式設定」。PR 1(0023: 苦手な語の出やすさ)の続き。

## 仕様と、現状の突き合わせ

| 仕様 | 状態 |
| ---- | ---- |
| 複数ローマ字表記 | **済み**(Phase 2。し = si/shi、ん = n/nn/xn、っ = 子音の重ね・xtu、拗音、長音)。**この PR で、小さい文字を分けて打つ書き方(kixya・fuxa など)を足した** |
| **入力方式設定** | **この PR**。0003 に「設定 UI は Phase 13」とあった |

## 運営者が決めたこと(計画への「推奨案で」)

- 設定「**ローマ字の書き方**」は 3 択: **標準 / 訓令式で表示 / 表示どおりだけ**
- 距離の「文字数の分」は、書き方に関係なく、標準の長さ(設定で、距離が変わらないようにする)
- 小さい文字を分けて打つ書き方は、標準で受け付ける

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 方式 | **標準(既定)**: ヘボン式(shi・chi・tsu・sha・ji)で表示し、si・ti・tu・sya・zi など、ほかの書き方も受け付ける(これまでと同じ)。**訓令式で表示**: si・ti・tu・hu・zi・sya・zya…で表示し、ほかの書き方も受け付ける。**表示どおりだけ**: 表示された書き方(ヘボン式)だけを受け付け、ほかの書き方は、そのキーで**ミス**になる | 表示の好みと、検定などの練習(厳密)を、分けて選べる |
| 2 | マッチャー | `createMatcher(読み, { style, strict })`(`romaji.js`)。`style`: `"hepburn"`(既定)か `"kunrei"`(知らない値は hepburn)。`strict: true` なら、各単位の先頭(表示の)表記だけを残す。訓令式では、し・ち・つ・ふ・じ・し/じ/ち の拗音・しぇ/じぇ/ちぇ を、訓令式の表記を先頭にする(**っ の重ねも、それに従う**: sshi → ssi、cchi → tti)。ふぁ・きゃ・ん・長音などは、違いがない | 表示(先頭の表記)と、受け付ける範囲を、別に選べる |
| 3 | 小さい文字を分けて打つ書き方 | 標準・訓令式で、「かな + 小さいかな」を分けて打つ書き方を、受け付ける(きゃ = kixya・kilya、しゃ = shixya・sixya、ふぁ = fuxa、てぃ = texi など)。**表示の(先頭の)書き方は、変えない**。表示どおりだけ では、受け付けない | 複数ローマ字表記の、よくある書き方。表示は、これまでと同じ |
| 4 | 設定 | ダッシュボードに「ローマ字の書き方」(ラベル・説明つきの選択肢)。`settings.js` の `inputStyle`(`standard` / `kunrei` / `strict`)に保存(記録とは別のキー)。壊れた値・知らない値は、既定(標準)に戻し、ほかの設定は保つ。以前の設定(`inputStyle` がない)は、ほかの設定を保って既定を補う。**連続タイピングにも、用語確認にも、効く**(欄は、どちらのモードでも出す) | 入力の設定なので、モードによらない |
| 5 | 距離 | 距離の「文字数の分」は、**書き方の設定に関係なく、標準(ヘボン式)の長さ**で数える(`createMatcher(読み).canonicalLength`)。速さの分は、これまでどおり、実際に打った打鍵数(`matcher.typed`)で数える | 書き方の設定で、距離の増え方が変わらないように(0022) |
| 6 | 保存・スコア | 記録の形・版(`DATA_VERSION` 2)・スコアの式は、変えない。設定だけを、設定のキーに保存 | 影響を、最小に |
| 7 | 語録 | 変えない。語録の `romaji`(宣言された書き方)は、標準・訓令式で、全候補が入力できること(テスト) | 既存のテストを、保つ |
| 8 | 詳細ページ | ゲームを **0.9.0** に。FAQ「ローマ字は、どの書き方でも入力できますか?」・更新履歴を更新 | 入力の挙動が変わった |

## 影響(確認したこと)

- **表示の長さ**: 訓令式にすると、語録 180 語のうち **37 語**で、表示の長さが変わる。**短くなる語**(cchi → tti、shi → si、tsu → tu など)が多く、**長くなる語**もある(じゅ = ju → zyu: ばーじょん・じゅぎょう・こじんじょうほう など 8 語)。全体の長さは、約 **2% 短い**(平均 8.39 → 8.23 文字)。距離は、標準の長さで数えるので、変わらない。訓令式の人は、語を打ち終えるのが、約 2% 早いだけで、バランスへの影響は、ごくわずか(0022 の階段は、標準の書き方で確認したまま)
- **表示どおりだけ**: 標準より、ミスが出やすい(別の書き方が、ミスになる)。ミスは、これまでと同じに数える(距離が縮み、成績・苦手なキーに記録される)。**難しさの選択**であり、ランキングは、この端末の中だけ
- **苦手なキーの記録**(0005): 「期待したキー」は、画面に表示している書き方の、次の 1 文字。訓令式で遊ぶと、そのキー(s・t・z など)で記録される
- 「標準」の動きは、これまでと同じ(先頭の書き方も、受け付ける範囲の広さも)。小さい文字を分けて打つ書き方が、受け付ける範囲に加わっただけ
