# 0030 Phase 16 PR 1: キャラクターの絵の描き直し

日付: 2026-09-21 / 対象: Phase 16「ポップなデフォルメと役職別個性。見た目・動き・セリフ・乗り物を変更。開始・接近・クリア・ゲームオーバー演出。BGM・効果音・音量・ミュート。音声は将来対応」。

Phase 16 は 3 つの PR に分ける(運営者が決めたこと。計画への「推奨案で」)。**この PR(1)**: 絵の描き直し。**PR 2**: セリフと演出(開始・接近・クリア・ゲームオーバー)。**PR 3**: 音(効果音・BGM・音量・ミュート)。

## Phase 16 の全体の決定(計画への「推奨案で」)

| 項目 | 決定 |
| ---- | ---- |
| 絵の作り方 | AI が SVG を、コードで描く。運営者が見て、直しを往復する。ファイルの名前・場所・`viewBox` は、そのまま(差し替えだけで済む)。外部の素材は使わない(権利の確認が要るため) |
| Phase 17・23 との境目 | 演出は、**全役職共通の型**(役職ごとの違いは、絵・動き・セリフだけ)。役職専用の演出は Phase 17。音は、基本の仕組み(効果音数種類・BGM 1 曲・音量・ミュート)だけ。職種・役職ごとの BGM・役職別の効果音・演出のスキップ設定は Phase 23 |
| 音の作り方 | ファイルを使わず、Web Audio で合成する(PR 3) |
| 音の既定 | オフ(仕事中に、突然音が出ないように)(PR 3) |
| 音声(声) | 作らない。将来対応 |

## この PR の決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 絵の方向 | **ポップなデフォルメ**: 頭と目を大きく、輪郭を太く(`#1b2033`)、角を丸く。ほおの赤み・汗・きらきらで、表情を出す | サイトの「ポップ・カジュアル」(design-system)に合わせる |
| 2 | 役職の個性 | 先輩 = 走る・ネクタイが赤い・口を開けて追う / 係長 = 丸いメガネで自転車 / 部長 = 緑のセダンの窓から、太い眉で見る / 社長 = サングラスと笑顔のリムジン(金のライン) / 会長 = 白い髪とひげ、モノクルで、ヘリコプターの風防の中 | 縮小(高さ 64px)しても、役職を見分けられる。動き(0028)の個性を、絵でも出す |
| 3 | 乗り物 | 役職の乗り物(徒歩・自転車・セダン・リムジン・ヘリコプター。`roles.json` の `vehicle`)は、そのまま。乗り物の中の人が、大きく見えるようにした | 仕様の「乗り物を変更」は、見た目の描き直しとして行う。乗り物の種類を変えると、動き(0028)・文言・記録との対応が変わるため、変えない |
| 4 | あなたの絵 | ふつうの顔(`player.svg`)と、**焦った顔**(`player-panic.svg`。目を見開き、口を開け、汗)の 2 枚 | 危ない状態を、色・文字だけでなく、表情でも伝える |
| 5 | 焦った顔の切り替え | 画面に 2 枚を置き、`.scene.is-danger`(距離が 25% 以下。ゲージと同じ判断 `isDanger`)のとき、CSS で入れ替える。JS・`src` の書き換えはなし | 最初から両方を読み込むので、切り替えで待たされない(絵は各 1KB 前後)。判断は、既存の `is-danger` を使うので、ずれない |
| 6 | 大きさ | 追ってくる人 120×80・あなた 64×80(`viewBox`・画面の `width`・`height` は、変えない) | レイアウトが、ずれない。動きの CSS(0028)が、そのまま効く |
| 7 | 絵の安全 | 使うのは図形(`svg`・`g`・`rect`・`circle`・`ellipse`・`line`・`path`・`polygon`)だけ。文字・画像・スクリプト・スタイル・動き・フィルタ・`use`・外部の参照は使わない。色は、決めた配色(13 色。サイトの配色 + 少数)の 16 進だけ。1 枚 4KB 以内 | 将来、管理画面などから絵が入っても、安全に(背景 0029 と同じ考え) |
| 8 | デフォルメの検査 | 顔(肌の色の円)の直径が、絵の高さの 25% 以上であること | 「頭が大きい」を、テストで守る |
| 9 | 詳細ページ | ゲームを **0.14.0** に。更新履歴を追加。遊ぶ画面の画像(`play.webp`)を撮り直した | 画面が変わった |
| 10 | 影響 | **ゲームの規則・距離・バランス・スコア・記録・語録・動き(CSS)は、変わらない**。追加は、あなたの絵 1 枚と、その切り替えの CSS だけ | 見た目だけ |

## テスト

- 新規 `tests/characters.test.js`(34 件): 5 役職 + あなたの 2 枚の絵が存在し、すべて違う・画面の大きさ指定が `viewBox` と同じ・4KB 以内・使う要素と属性が図形だけ・配色の 13 色だけ・輪郭が濃い色・顔が大きい(25% 以上)・焦った顔の切り替え(HTML の 2 枚・CSS の規則・同じ大きさ)
- `tests/scene.test.js`: あなたの絵のクラス名の変更に合わせて更新
- ブラウザ(headless Edge + `wrangler pages dev`、**実際のキー入力**)**24 項目成功**: 5 役職それぞれで、追ってくる人の絵が読み込まれて表示される・通常はふつうの顔・**危ないとき(ミスを重ねて距離を減らす)に、焦った顔へ入れ替わる**・375px で、横スクロールなし・入力欄が画面内・外部通信なし・読み込み失敗なし・コンソールのエラーなし
- 見た目: 5 役職(通常・危ない)と 375px のスクリーンショットを、目で確認した

## 未確認・既知事項

- **絵の好み・出来ばえは、あなたの判断が要る**(AI が、コードで描いた、フラットな図です)。直したい点(顔・色・大きさ・役職の特徴)を教えてもらえれば、SVG のファイルを直すだけで、調整できる(名前・大きさは、そのまま)
- 役職の絵は静止画。動き(0028)は、CSS で付ける
- スクリーンリーダー・スマートフォンでの実機確認は未実施(場面は飾りで、`aria-hidden`)。Microsoft Edge(Windows・headless)だけで確認
