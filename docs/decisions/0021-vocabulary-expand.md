# 0021 Phase 11 PR 2: 語録の拡充と、バランスの再確認

日付: 2026-09-21 / 対象: Phase 11「職種専用語録」。PR 1(0018: 確認シートと統計ツール)の続き。

## 運営者が決めたこと(計画への「推奨案で」)

- 難易度は、決定ログ 0006 の**読みの長さの決め**にそろえる(下記 1)
- 語を、職種ごとに **30 語**に増やす。役職ごとの語の出し分けは、しない
- バランスは、シミュレーションで**再確認**し、0006 の表からずれたときだけ、調整する

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 難易度の決め | **読みの単位数(小さい「ゃゅょぁぃぅぇぉ」は前の文字と合わせて 1、「っ」「ー」「ん」は 1)が 3 以下 = 1、4〜5 = 2、6 以上 = 3**(0006 の決めのまま)。決めと違っていた **17 語**を、決めに合わせた(engineer 2・food-service 2・office 2・retail 3・sales 3・teaching 5) | 決めと語のデータが食い違っていた(PR 1 の警告)。難易度は、まだ、距離の計算に使っていない(PR 3 で使う)ので、この変更で、遊びの結果は変わらない |
| 2 | 語数 | 各職種 **16 → 30 語**(+14 × 6 = **+84 語、計 180 語**)。追加の id は `<職種>-017`〜`-030`(**既存の id は、消さない・つけ替えない**。復習リスト・記録の語の対応が、壊れないように) | 1 回のプレイで使う語は 14〜16 語。30 語あれば、毎回、違う顔ぶれになる |
| 3 | 追加した語の内容 | すべて **AI(私)の下書き**。説明は、80 字以内・1 文・一般に確立した意味だけ・ブランド名なし。使い方が会社・地域・制度で違う語には、確認メモ(`docs/vocabulary-review-notes.json`)を付けた(9 → **35 件**)。**運営者の確認(`docs/vocabulary-review.md`)は、これから** | 語録は、AI の下書きを人間が確認してから公開する(CLAUDE.md) |
| 4 | カテゴリ | 3 種類以上に。engineer に「セキュリティ」、office に「経理」「総務」、sales に「顧客対応」「営業管理」、teaching に「学校運営」を追加(retail・food-service は、もとから 3 以上) | 職種の中で、分野の偏りを減らす |

| 7 | 点検 | 警告を **0** に(`tests/vocab-stats.test.js` の「警告は、増やさない」を、「**警告がない**」に。職種ごとに 30 語で、id が連番であることも検査)。今後、警告が出たら、テストが失敗する | PR 1 で、PR 2 に予告していた |
| 8 | バランス | 下記。**`drain_per_second` を、全役職で約 3% 下げた**(1.25→1.21・1.9→1.84・2.1→2.04・2.2→2.13・2.3→2.23)。ほかの値(初期距離・獲得・ミスの減り・目標語数)は、変えない | 語が少し長くなり(全体の平均 4.4 → 4.6 文字)、クリア率が最大 9 ポイント下がったため |
| 9 | 役職ごとの語の出し分け | **しない**(30 語すべてが、5 役職すべてで、出る) | 承認済み。役職ごとの難しさは、距離(`roles.json`)で決める(0006) |
| 10 | 詳細ページ | ゲームを **0.6.0** に。更新履歴を追加。詳細ページ(生成)を作り直した | 語録が変わった |

## バランスの再確認

同じシミュレーション(実際の語録とエンジン・打鍵の 4 モデル・各 4000 回)で、クリア率を比べた。ふつう = 2.5 打鍵/秒・ミス 8%、遅い = 1.2・8%、速い = 4・5%、達人 = 6・3%。

| 役職 | 遅い | ふつう | 速い | 達人 |
| ---- | ---- | ---- | ---- | ---- |
| 0006 の表(16 語) | 先輩 87% | 89%(係長)/ 67%(部長)/ 50%(社長) | 会長 75% | すべて 100% |
| 語を 30 語に(値は、そのまま) | 先輩 78% | 係長 81% / 部長 59% / 社長 41% | 会長 69% | 100% |
| **`drain_per_second` を約 3% 下げた(採用)** | **先輩 87%** | **係長 88% / 部長 67% / 社長 53%** | **会長 76%** | **100%** |

- 先輩(ふつう)の 100%・所要時間(遅い 120 秒・ふつう 65 秒・速い 43 秒・達人 29 秒)は、0006 と、ほぼ同じ(1 プレイ 1〜3 分)
- 会長は、ふつうの人には 0%(裏ボス)のまま
- 社長の 53% は、0006 の 50% より 3 ポイント高い(許容の範囲)。**いまの数字は、モデルの打鍵での目安**で、実際の人間のプレイでの手ごたえは、未確認(遊んで調整する)
