# 0076 スタート前の難易度の選択欄を戻す(Issue #173)

> **取り消し(2026-10-03)**: Jさんの「ここでいってる難易度は役職の話やから"難易度"はいらない」を受けて、0079 で、この選択欄をまた外した。以下は、当時の記録。

## 理由

Issue #173 の運営者のコメント「ここからゲーム感を出してほしい / 職種と難易度が選べなくなった」を受け、確認した(選択肢 1「難易度が選べるようになった」)。運営者の回答は「1. 難易度が選べるようになった」(2026-10-03)。0061(Issue #144)は「難易度 = 追ってくる人(役職)」として、スタート前の難易度の選択欄を外していたが、その判断を、この決定で置き換える(役職と難易度は、別の軸として、両方選べる)。

## 変更

- スタート前のフォームに、職種・追ってくる人と並んで、「難易度」のドロップダウン(やさしい / ふつう / むずかしい)を戻した(`data-difficulty-list`)。選んだ難易度の説明・経験値の倍率・まだ挑戦できない難易度の説明を、下に出す。
- 既定は「ふつう」。**むずかしいは、その役職を「ふつう」でクリアするまで、ロック中**(`disabled` + 文字のバッジ。0037 の解放の決めのまま)。役職を選び直すたびに、ロック状態を作り直す。
- 用語確認では、難易度の欄も隠す(役職と同じ。追いかけがないため)。
- 前回の選択は、ゲーム設定の `lastChoice.difficulty` に保存する(0059 で、すでにある項目)。いま選べない値は選ばない。
- 難易度の中身・倍率・記録・ランキング・実績・経験値の決めは、変えていない(0037)。やさしいは、ランキング・役職クリアの実績・会長の解放に数えない。

## 影響範囲

- `index.html`・`view.js`・`main.js` のつなぎだけ。`difficulty.js`・`engine.js`・`records.js`・`storage.js`・`roles.json`・`difficulties.json` は変えていない。
- 記録の版(`DATA_VERSION` 5)・キー(`v1`)・プライバシーポリシーの版は、変えていない。
- ゲームの更新履歴(`products.json`)を 0.31.0 に。ダッシュボードの画面を撮り直した。

## テスト

- `tests/difficulty-wiring.test.js`(HTML の目印・並び・ラベル・描画とイベントのつなぎ・開始の送信・用語確認での非表示)を含む `npm run check`。
- Edge で、1280px・360px を確認: 横はみ出しなし・既定がふつう・むずかしいがロック中・やさしいを選ぶと説明が変わる・用語確認で欄が隠れる・選んだ難易度が `lastChoice` に保存される。
