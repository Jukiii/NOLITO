# 0006 Phase 4(続き)語録の拡充と、1プレイ1〜3分へのバランス再調整

日付: 2026-09-20 / 対象Phase: 4

Phase 4 の要件「1プレイ1〜3分」を満たすため、語録を増やし、目標語数とバランスを再調整した(決定ログ 0005 で別PRにするとした対応)。
**このログの役職パラメータとクリア率は、0004 のバランス表を置き換える。**

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 語録の数 | 職種ごとに6語を追加し、16語/職種(計96語)。version を `0.2.0` に。追加分の id は `<職種>-011`〜`016` | 目標語数を増やしても、同一ゲーム内で語が重複しないため |
| 2 | 追加語の内容 | 一般に確立した意味だけを書く。難易度は読みの単位数で 1(3以下)・2(4〜5)・3(6以上)。全役職の対象。**下書きで、人間の確認が必要** | 語録は人間の確認が必須(P14・24) |
| 3 | 目標語数 | 先輩14・係長14・部長15・社長15・会長16 | ふつうの打鍵速度で約1分になる語数 |
| 4 | 役職のパラメータ | 下表。0004 と同じ方法(実際の語録とエンジンによるシミュレーション)で、役職ごとに再探索した | 語数が増えると、同じ値ではクリア率が大きく下がるため(係長でふつうの人 89% → 8%) |
| 5 | 会長の難易度 | 速い人で76%(Phase 3 の77%とほぼ同じ)。ふつうの人にはクリアできない裏ボスのまま | 難易度を保つ |

- 倍率(1.0 / 1.2 / 1.5 / 2.0 / 3.0)は変更なし
- 役職が進むほど難しくなること(初期距離は減り、減少速度・ミス・語数・倍率は増える)は、単体テストで検証している

## 1プレイの長さ

| 打鍵速度 | 先輩(所要時間の平均) |
| ---- | ---- |
| 遅い(1.2打鍵/秒) | 117秒(約2分) |
| ふつう(2.5) | 63秒(約1分) |
| 速い(4) | 42秒 |
| 達人(6) | 29秒 |

- ふつう以下の打鍵速度では、仕様(1〜3分)に収まる。速い人は1分を切る(速い人向けの難しさは、上の役職で出す)
- **実測**(headless Edge で、1文字0.4秒・語ごとに1秒の反応時間で実際に入力): 先輩・エンジニア 62.2秒、先輩・接客販売 63.8秒(シミュレーションの63秒と一致)
- ふつうの打鍵速度の上の役職は、62〜66秒(社長・部長・係長)

## 仕様・計画からの変更点

- 決定ログ 0005 の計画では「目標語数を12〜15語」としたが、会長が16語を必要とするため、14〜16語にした(語数の下限12は、テストで検証する)
