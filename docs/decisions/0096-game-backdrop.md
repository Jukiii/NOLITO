# 0096 プレイ中の画面全体に追いかけ演出を加える(Issue #235)

## 理由

プレイ中の場面だけでなく、画面全体に「先輩に追いかけられる」演出を広げる。

## 決定

- プレイ画面(`data-view="play"`が表示中)だけ、ゲーム内の追いかけシーンを画面全体の背景として表示する。選択中の職場背景・追う人・プレイヤー・道路を使い、プレイ画面の端から端まで追いかけっこが見えるようにする。
- ゲーム枠は透明、お題カードは半透明にして、文字を読みやすく保ちながら追いかけシーンを背面に見せる。新しい外部画像通信は加えない。
- 動きを減らす設定では、既存の全体ルールによりアニメーションを停止する。モバイルのレイアウトや入力操作には影響させない。HTML・ゲームロジック・記録・音・ゲームの進行は変えない。

## テスト

- `tests/arcade-ui.test.js` で、既存のシーン全体（職場背景・道路・追う人・プレイヤー）がプレイ中だけ固定全画面になること、モバイルで人物を縮小すること、お題カードが半透明であることを検査する。動きの軽減は共通ルールで検査する。
- `npm run test` と `npm run check` を実行する。

## プレビューURLの共有

- 画面の変更を実装したら、PRコメントにブランチのCloudflare PagesプレビューURLと、変更箇所を確認する操作を書く。
- URLはデプロイ情報で実際のブランチプレビュー先を確認してから記載する。推測でURLを作らず、まだデプロイされていない場合は、確認できていないことをコメントする。
