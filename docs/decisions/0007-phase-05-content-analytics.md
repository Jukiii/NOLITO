# 0007 Phase 5 記事・プロダクト紹介・Google Analytics・広告の枠の決定事項

日付: 2026-09-20 / 対象Phase: 5

## スコープ

含めるもの: 記事(Markdownから静的HTMLを生成)、プロダクト紹介(`products.json`)、Google Analytics(同意つき)、プライバシーポリシーとサイト紹介、広告の枠(無効)と配置ルール。

含めないもの(該当Phase): 管理画面からの記事投稿(P26)、商品データの本格的な構造・`/software/` `/tools/`(P6〜8)、広告事業者・アフィリエイトの導入と収益化ポリシー(P29)、問い合わせフォーム(P10)、トップページの構成・検索(P20)、利用規約(P29・30)、セキュリティヘッダー(P27)、`sitemap.xml` / `robots.txt`(仕様書にない)。

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 記事の管理元 | `content/articles/<スラッグ>.md`(先頭にYAMLの情報)。管理画面(P26)がないため、GitHubのPRで公開する。PRのレビューが「公開前の人間の確認」 | 仕様「Markdownを管理元」。将来の管理画面は、このMarkdownを書き込む形にできる |
| 2 | 記事のビルド | `scripts/build-articles.mjs`(`npm run build:articles`)が、各記事のページ・一覧・索引(`public/data/articles.json`)を生成。**生成物はコミットする**(Cloudflare Pagesのビルドは使わない)。`npm run check` の単体テストが「生成物が原稿と一致するか」を検査する | 静的HTMLは検索エンジン・広告審査に有利。Phase 0 の「ビルドなし」を保てる |
| 3 | 記事の安全性 | 本文の生のHTMLは、実行せず文字にする。危険なリンク(`javascript:` など)と、使えない画像の場所は**ビルドを失敗させる**(黙って捨てない)。画像には alt が必須。本文の見出し1は不可。外部リンクには `rel="noopener noreferrer"` | 将来、管理画面など他の経路からも書かれる前提で、安全側に倒す |
| 4 | 記事の検証 | title(100字まで)・description(10〜160字)・date(実在する日付)が必須。スラッグは英小文字・数字・ハイフンだけ。`draft: true` は公開しない(本文の変換もしない) | 誤りをビルド時に気づけるように |
| 5 | 記事のSEO | 正規URL(canonical)・OGP(画像なし)・公開日と更新日(`<time>`)。サイトのURLは `public/data/site.json` の1か所(現在は `https://nolito.pages.dev`) | 独自ドメインにしたら、ここを変える |
| 6 | 最初の記事 | 「上司から逃げろ」の遊び方とローマ字入力のコツ(私が下書き。PRのマージが公開) | 内容は実装と照合済み |
| 7 | プロダクト紹介 | `public/data/products.json`(id・カテゴリ・題名・説明・状態・URL・更新日)。`/games/` の一覧をここから描画。状態は、色だけでなく文字(公開中/テスト版/準備中)でも示す。トップページは変更しない | 項目は Phase 6 で拡張する |
| 8 | Google Analytics | **同意するまで、Googleに何も要求しない(オプトイン)**。ページビューのみ。**測定IDが正しい形で設定され、かつ本番のホストのときだけ**動く(既定は空で、何も動かない)。同意は `nolito:consent:v1` に、ポリシーの版つきで保存し、版が上がると再確認する | プライバシー優先。プレビュー・ローカルの計測データ汚染を防ぐ |
| 9 | 同意のUI | ヘッダーの直後に差し込む非モーダルのバナー(画面の内容に重ねない)。「同意する」「同意しない」は同じ見た目・同じ重み。フッターの「アクセス解析の設定」から、いつでも変更・撤回できる。撤回すると、無効化の印(`ga-disable-<ID>`)を付け、`_ga` のCookieを(ドメイン属性の3通りの指定で)消す | 拒否を選びにくくしない |
| 10 | 法務ページ | `/privacy/`(プライバシーポリシー・版1)と `/about/`(サイト紹介)を追加し、フッターにリンク。文面は**下書き**で、運営者の確認が必要。お問い合わせ先は「準備中」(問い合わせ手段は P10) | 計測を始める前にポリシーが必要 |
| 11 | 広告の枠 | `data-ad-slot`(page / article / game-result)を、ゲームの外のページ・記事・結果画面に置く(常に非表示、場所も占めない)。プレイ画面・ダッシュボードには置かない。広告事業者のスクリプトは入れない(P29)。`initAdSlots` は、許可されない配置の枠を取り除き、有効かつ描画処理があるときだけ表示する | 「ゲーム外・ゲーム終了画面」のルールを、テストで守る |
| 12 | 依存 | `marked`・`yaml`(devDependencies。公開物には含まれない) | 記事の変換 |

## 運営者にお願いする設定

- **GA4のプロパティを作り、測定ID(`G-XXXXXXXXXX`)を `public/assets/js/config/analytics.js` の `measurementId` に入れる**(入れるまで計測は無効)
- GA4の管理画面で、**Google シグナルと、広告向けのデータ共有をオフ**にする(プライバシーポリシーの「広告の配信には使いません」と合わせるため)。データの保持期間も確認する
- プライバシーポリシーと、サイト紹介の文面を確認する。**お問い合わせ先**を決める(決めるまで「準備中」)
- ポリシーの内容を変えたら、`privacy/index.html` の `data-policy-version` と `analyticsConfig.policyVersion` の版を上げる(同意を取り直す。両方の一致はテストで検査)
- 独自ドメインにしたら、`public/data/site.json` の `url`、`analyticsConfig.hosts`、記事とポリシーの canonical を変える

- ブラウザ操作(headless Edge)71項目成功:
  - 記事の一覧・ページ(見出し・日付・タグ・canonical・OGP)、JavaScriptなしでも本文が読めること、サイト内リンク
  - **既定の状態(測定IDが空)では、8ページを開いてもサイト外への通信が0件**、バナーも出ない

## 未確認・既知事項

- **実際のGoogleのサーバーとの通信は未確認**(測定IDがないため)。スクリプトの読み込みは、スタブで確認している
- プライバシーポリシーの文面は下書き。法令(個人情報保護法・電気通信事業法の外部送信規律など)への適合は、運営者が確認する必要がある
- Cookie の削除は、この端末・このホストの `_ga` 系に限る(ブラウザの仕様で、消せない場合がある)
- 記事の画像は、まだ使っていない(仕組みは alt の検証まで)
- 記事が増えたときの、タグでの絞り込み・検索は Phase 20
- プレビュー(`*.pages.dev` の別名)は計測の対象外。本番でのみ計測される

- GA4 の測定 ID(`G-5T8P9H748P`)を `public/assets/js/config/analytics.js` に設定した。これで、**本番のホスト(`nolito.pages.dev`)で、同意した人のページビューが計測される**。プレビュー・ローカルは、これまでどおり対象外

  - 撤回で、無効化の印(`ga-disable-G-5T8P9H748P`)が付く
- マージ後の確認: 運営者が、本番で「同意する」を選び、GA4 の「リアルタイム」に 1 件表示されることを確認する
