# 0066: プレイヤー・記録のページ(ニックネーム・ランキング・称号・記録の管理をタブで)(Issue #163)

## 背景

運営者が、Issue #163 で依頼した(2026-10-02)。「記録の書き出し、ランキング、称号は別ページでタブ?管理にして。ニックネームの設定も」。ゲームのダッシュボードに、設定・記録の欄が並び、スタートまでが長かった。

## 決定

- 新しいページ `/games/escape-boss/profile/`(noindex)に、次の 4 つのタブで移した。ダッシュボードからは、欄を取り除き、ページへのリンクの節だけを置いた。ナビの「ゲーム」の子にも「プレイヤー・記録」を足した。
  - **プレイヤー**: レベル・経験値・ニックネーム(12 文字まで)・称号の設定。
  - **ランキング**: 端末内のランキング、オンラインランキング(最初に開いたときに読む)。
  - **称号・実績**: 実績の一覧(隠し実績は、解放するまで内容を隠す)。
  - **記録の管理**: JSON の書き出し・読み込み(確認のダイアログを経由する)。
- 依頼文の「タブ?」は、疑問符が付いていたので、私が「タブで切り替える 1 ページ」と解釈した。別の形(ページを分ける・並べるだけ)がよければ、Issue で依頼してもらう。
- タブは、kii-michi と同じ作り(`role="tablist"`、矢印キー・Home・End、roving `tabindex`)。`?tab=` で、タブをアドレスに反映する(共有・ブックマークできる。不正な値は先頭)。選択中は、色だけでなく、太字と下線でも示す。

## 変えないもの

- 記録の形・版(5)・キー、書き出し・読み込み・ランキング・ニックネームの処理・API。プレイ中の挙動。プライバシーポリシーの版(新しいデータの取得・送信はない)。
- ダッシュボードの `view.js`・`main.js` から、移した欄の描画・イベントを取り除いた(`profile-page.js` が持つ)。実績の 1 件の描画は、結果画面と共通のため、`achievement-item.js` に切り出した。

## 影響範囲

- ダッシュボードを開く利用者は、これらの欄をダッシュボードで見つけられなくなる。リンクの節で案内する。
- 既存のブックマーク(`/games/escape-boss/`)は、そのまま使える。

## テスト

- `tests/profile-page.test.js`(タブの計算・HTML の構造・スクリプトが探す `data-*` が HTML にあること・CSS のトークン/タップ領域)を追加。`tests/backup-wiring.test.js`・`difficulty-wiring.test.js`・`hidden-achievements-wiring.test.js`・`levels-wiring.test.js` を、移した先に合わせて直した。
- ブラウザ(幅 360px)で、全タブに横のはみ出しがないこと、ニックネームの保存、矢印キー・Home・End、`?tab=`、書き出し→読み込みのダイアログ→置き換えを確認した。
