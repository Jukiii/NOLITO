キーみち

テスト版

キーボードだけで作業するための「キー操作ルート」を、自分の作業手順に合わせて組み立てるツール。ショートカット一覧とチートシートも作れます。

詳しい説明

アプリごとに、よく使うキー操作を登録し、自分の作業の順番に並べて「ルート」にできます。ルートは、マウスに手を伸ばさずに作業を進めるための、あなただけのキー操作の道すじです。

ショートカットの辞書ではありません。アプリごとのショートカットは、OS・バージョン・設定で違うため、辞書は入れていません。あなたが使うアプリと操作を、あなたの作業手順に合わせて登録します。

登録した内容から、アプリ別のショートカット一覧と、印刷(PDF に保存もできます)や Markdown で使えるチートシートを作れます。

「練習」の画面で、ルートの手順を、順番どおりに、キーを押して練習できます。答えのキーは隠れていて、思い出して押します。ブラウザや OS が先に処理するキーなどは、判定できないので、答えを見て確認します。練習の結果は、保存しません。

登録した内容は、お使いのブラウザの中にだけ保存されます(送信しません)。JSON ファイルに書き出して、バックアップすることもできます。

よくある質問

登録した内容は、どこに保存されますか?

お使いのブラウザの中(LocalStorage)にだけ保存され、サーバーには送りません。ブラウザのサイトデータを消すと、なくなります。「設定」の「JSON ファイルに書き出す」で、バックアップできます。

ショートカットの辞書は入っていますか?

いいえ。アプリごとのショートカットは、OS・バージョン・設定で違うため、辞書は入れていません。自分が使うアプリと操作を、自分で登録します。

「キーを押して入力」で、記録できないキーがあります。

Ctrl+W(タブを閉じる)や Alt+Tab など、ブラウザや OS が先に処理するキーは、押しても記録できません(押すと、タブが閉じるなどします)。キーの入力欄に、文字で入力してください(例: Ctrl+W)。

Mac でも使えますか?

使えます。「設定」で、キーの表記を macOS(Control / Option / Command)に切り替えられます。ただし、Mac での確認は、まだ十分ではありません。

スマートフォンで使えますか?

登録・一覧・チートシートと、答えを見て確認する練習は、使えます。「キーを押して入力」と、キーを押して判定する練習には、キーボードが必要です。

有料ですか?

いいえ。すべての機能を、無料で使えます。

練習モードはありますか?

あります。「練習」の画面で、ルートを選ぶと、その手順を、順番どおりに練習できます。答えのキーは隠れていて、キーを押すと、合っているかを判定します。ヒント・スキップ・やめるもできます。ただし、Ctrl+W や Alt+Tab など、ブラウザや OS が先に処理するキーと、単独の Tab は、判定できないので、答えを見て確認します(押しても反応しないキーは、その場で「自己確認にする」に切り替えられます)。練習の結果は、保存されません。
