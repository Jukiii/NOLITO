# 0096 プレイ中の画面全体に背景演出を加える(Issue #235)

## 理由

プレイ中の画面に、場面のスクロールとは別に、画面全体を使ったゲームらしい演出を加える。

## 決定

- プレイ画面(`data-view="play"`が表示中)だけ、画面背景に薄いネオン色の光と格子を CSS でゆっくり流す。
- 配色は既存のアーケード用トークンを使う。HTML・ゲームロジック・記録・音・ゲームの進行は変えない。
- 動きを減らす設定では、既存の全体ルールによりアニメーションを停止する。モバイルのレイアウトや入力操作には影響させない。

## テスト

- `tests/arcade-ui.test.js` で、背景演出がプレイ中だけ適用され、ゆっくり動き、動きを減らす設定の抑制ルールが有効であることを検査する。
- `npm run test` と `npm run check` を実行する。
