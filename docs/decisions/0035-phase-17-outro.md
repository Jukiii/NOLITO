## 決定(計画への「推奨案で」)

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 決め方 | `roles.json` の `scene.outro`(`clear` と `over`)に、見せ方の名前を書く。名前は `scene.js` の `OUTRO_STYLES` にあるものだけ(`outroStyleOf` が検証。知らない値・別の種類の値・`__proto__` などは `null` = 全役職共通の演出になる)。場面の `data-outro` に入り、CSS が動かす | データで、あとから直せる(役職の動き `scene.motion` と同じ) |
| 2 | クリアの 5 種類 | **先輩 = へたり込む**(傾いて沈む)/ **係長 = 自転車が転ぶ**(大きく傾いて倒れる)/ **部長 = 車が止まる**(少し戻り、揺れて止まる)/ **社長 = ゆっくり去る**(遠ざかり薄くなる。**金だけの**紙吹雪)/ **会長 = ヘリコプターが上昇して去る**(場面の上へ) | 役職の乗り物・動き(0028)に合わせる |
| 3 | ゲームオーバーの 5 種類 | **先輩 = 飛びつく**(追いつく動きに、跳ねを足す)/ **係長 = 追い越す**(あなたの横を通り抜け、場面の右へ消える)/ **部長 = 急ブレーキ**(前のめりに揺れて、あなたの前に止まる)/ **社長 = 輝き**(目の前で止まり、あなたが金の輝きに包まれる)/ **会長 = オーラ**(頭上に浮かび、主役の色のオーラが包む) | あなたはこれまでどおり、ふらつく(共通) |
| 4 | 変えないもの | 演出の長さ(**約 1.2 秒**。動きは 0.5〜1.1 秒)・文字(「逃げ切った!」「つかまった…」)・セリフの吹き出し・**結果を演出の前に保存する順序**・Enter/スペース/Esc/クリックで飛ばせる・動きを減らす設定(0.8 秒の文字だけ)・音(0032) | 0031 の決まり |
| 5 | ちらつかない | 動くのは、位置・大きさ・傾きと、ゆっくり(0.8 秒以上)の不透明度だけ。色・明るさ・影・背景色は変えない。輝きは、1.1 秒かけて、ゆっくり現れる(1 回だけ。点滅しない)(0028 の決まり。テストが検査) | 光の点滅を避ける |
| 6 | 最後の状態で止まる | 専用の動きは、すべて `forwards`。動きを減らす設定では、最初から最後の状態になる(全体の規則がアニメーションだけを止める) | 0031 と同じ |
| 7 | 共通の演出は残す | 全役職共通の規則(0031)は、そのまま残し、専用の規則(`[data-stage][data-outro]` で、属性を 2 つ持つので、共通より強い)が、上書きする。`scene.outro` がない・無効な役職は、共通の演出になる(落ちない) | 将来、役職を足しても、安全 |
| 8 | 輝きの飾り | 場面の中に `.scene__glow`(`aria-hidden`。ふだんは出ない・クリックを受けない)。社長(金 = アクセント)と会長(主役の色)だけが使う。色はトークン | 色の直書きをしない |
| 9 | 画面・main.js | `beginOutro` が、クリアかゲームオーバーかを `kind`(`clear`/`over`)に決め、セリフ・音・見せ方に、同じ値を使う。`view.showStaging(kind, text, outroStyle)` が `data-outro` を入れ、画面が替わる・新しいゲームで消す | 前の役職の見せ方が、残らない |
| 10 | 影響 | ゲームの規則・距離・バランス・記録の形と版・スコア・語録・ルール(0033・0034)は、変わらない。**見た目だけ** | — |
