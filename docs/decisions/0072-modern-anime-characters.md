# 0072 キャラクターの絵を、2020 年代のアニメ調に描き直す(Issue #166 PR 6)

## 理由

Issue #166 の運営者のコメント(2026-10-02)「平成初期〜中期のアニメ・ギャルゲーのような印象。2020 年代の日本アニメらしい、現代的なキャラクターデザインに。自然な顔・体型、目は大きすぎず、現代的な髪型・服装、落ち着いた配色、シンプルで親しみやすく」を受けた。

## 変更

- 7 枚(先輩・係長・部長・社長・会長・あなた・焦ったあなた)の絵を、同じ方向性で描き直した: 約 6〜6.5 頭身、小さめで自然な顔、小さめの縦長の目と細い上まぶた、細い線、肌・髪の 2 段の陰、人ごとに違う現代的な髪型と服、低彩度で落ち着いた配色。乗り手は、顔が見えるよう、大きめに描く。
- 6 コマのスプライトシートの形式・大きさ・乗り物の種類・動き・40KB の上限(0071)は変えない。`kakaricho.svg` は上限に近い(約 40.2KB)。足すときは、上限に注意する。

## 影響範囲

- 絵のファイルだけ(コード・記録・ランキング・バランス・語録は変えない)。ゲームの画面(play・result・check)を撮り直した。

## テスト

- `tests/characters.test.js`(絵の規則)を含む `npm run check`。Edge で、1280px・360px・横向き・動きを減らす設定・危ない状態を確認。

## 未対応

- 絵の好みは、運営者の確認待ち(今後の修正は、運営者の指示に従う)。
