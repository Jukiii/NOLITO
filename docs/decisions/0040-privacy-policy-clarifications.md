# 0040 プライバシーポリシーの補足(監査ログの保存期間・海外事業者の明記)

日付: 2026-09-24 / 対象: Issue #19(アカウントの一般公開の前提)の準備。

Issue #19 への提案([[0013-auth]]・#19 へのコメント参照)で見つけた、プライバシーポリシー版2の、既存の記載の**小さな抜け**を補った。新しい取り扱いを始めるものではない。

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 監査ログの保存期間 | §6-2(アカウント)に、「ログイン・削除などの操作の記録は、180日を目安に削除する」を追記した([[0013-auth]] 決定13の「180日で削除」と一致させる) | すでに実装・運用している保存期間を、ポリシーの本文にも明記する |
| 2 | 海外事業者の明記 | §7 に、Cloudflare, Inc.・Google LLC が「日本国外(アメリカ合衆国)の事業者」であることを明記した。具体的な保護措置(DPA・SCC など)の内容は、断定せず、「各社の公表情報をご確認ください」とした | 個人情報保護法は、外国にある第三者への提供を、通常の第三者提供と区別して扱う。未確認の具体的な法的主張は、書かない(安全側) |
| 3 | バージョン | **版は、上げない**(版2のまま)。CLAUDE.md の「端末内の保存の記載の追加や、連絡先の更新だけなら、版は上げない」の考えに沿い、**すでに開示している取り扱い(監査ログ・Cloudflare/Google の利用)を、より明確にしただけ**で、新しい取得・利用・提供を始めるものではないため | 実質的な取り扱いの変更がない補足に、同意の取り直しは、過剰 |

## 一般公開時の扱い

[[0013-auth]] の決定19「公開が、同意の取り直しの区切り」のとおり、**アカウントを一般公開するタイミングで、版3に上げる**(このタイミングでは上げない)。Issue #19 のほかの項目(独自ドメイン・お問い合わせ先・利用規約)が整い、実際に公開する PR で、あわせて版を上げる。

## 変更したもの

- 変更: `public/privacy/index.html`(§6-2・§7 に、上記の2点を追記。版は変えず)
- 新規: `docs/decisions/0040-privacy-policy-clarifications.md`

## 未確認・既知事項

- Cloudflare・Google の具体的な保護措置(標準契約条項など)の内容は、確認していない。運営者が、必要に応じて、各社の公表資料を確認してください(#19 のコメントにも記載)
- 独自ドメイン・お問い合わせ先の正式な運用・利用規約は、Issue #19 に残る(いずれも運営者の判断・作業が必要)
