# 0057: デザイン見本ページ(/theme-preview/)

## 背景

運営者から「全体のデザインを、テーマで選べるテストページを作って、選びたい」という依頼があった。案は 6 つ: 今のまま・ダーク・ホワイト・可愛い・クール(かっこいい)・メタリック(かっこいい)。仕様書に載っていない、デザインの選定のための見本ページ(運営者の直接の依頼)。

## 決定

- `/theme-preview/`(`noindex`。ナビ・フッターにリンクしない)に、6 案の切り替えと、6 案の並べた見本・部品の見本を置いた。ヘッダー・フッターを含むページ全体が、選んだ案に変わる。
- **本番のテーマ(`nolito:theme:v1`。ライト・ダーク・システム)は、変えない**。`isTheme` は、アカウントの表示設定の同期(サーバー側の検証)も使っているため、選ばれる前に、選択肢を増やさない。見本は、別の属性 `data-preview-theme`、別のキー `nolito:theme-preview:v1`(と `?theme=`)で動く。
- 案は、`tokens.css` と同じ**トークンの上書き**(色・線の太さ・角の丸み・影)で表す(`public/assets/css/theme-preview.css`。見本ページだけが読む)。部品の CSS は、共通のまま。メタリックの光沢(グラデーション)だけが、ボタン・カード・ヘッダーへの追加の規則。
- 「今のまま」「ダーク」は、`tokens.css` と同じ値(`tests/theme-preview.test.js` が検査)。新しい 4 案(ホワイト・可愛い・クール・メタリック)は、WCAG AA(文字 4.5:1・枠と焦点 3:1)を、テストが検査する。メタリックは、グラデーションのどの位置でも、文字が 4.5:1 以上。
- `--shadow-pop` は、宣言した場所で `var()` が解決される。案ごとに、影のトークンも宣言し直す。

## 影響範囲

- 利用者に見える変更は、ない(リンクのない見本ページだけ)。ポリシーの版・D1・環境変数の変更は、ない。端末には、見本の選択(`nolito:theme-preview:v1`)だけを保存する(見た目の好みで、個人を特徴づけない)。

## 既知の制限

- ゲームの場面の背景・キャラクターの絵は、見本に含めない(ライトテーマ向けの配色のまま。0046)。採用するときに、別に検討する。
- 見本は、代表的な部品(文字・ボタン・バッジ・カード・フォーム・ゲーム画面の模型)だけ。全ページの見え方の確認は、採用時に行う。

## テスト結果

- `npm run check`(2154 件)通過。ヘッドレスの Edge で、6 案の切り替え・URL への反映・`nolito:theme:v1` を書き換えないこと・375px 幅で横にあふれないことを確認した。

## 次の一手(運営者が案を選んだあと)

- 選ばれた案を、`tokens.css` へ移して本番に採用する(テーマの選択肢に足す場合は、`theme.js`・アカウント同期の検証・FOUC のスクリプト・コントラストのテストを、そろえる)。別の PR で行う。
