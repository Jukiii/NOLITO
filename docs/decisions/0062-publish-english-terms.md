# 0062: 英語のまま打つ語 23 語を公開する(Issue #131)

## 背景

0060 で、営業・事務・店頭業務・飲食・教育に足した 23 語は、下書きだった。運営者が、Issue #131 で「全部大丈夫」「語の範囲・説明の文言を全部公開して」と確認した(2026-09-30)。

## 決定

- 5 つの拡張ファイル(`content/vocabulary/<職種ID>.ext-english.md`)の、`draft: true` と `note`(確認のお願い)を消して、公開した。`review` は、ほかの公開語と同じ `pending` のまま(語録全体に、確認済みの語はまだない)。
- 語は、0060 のとおり(飲食は、POS の代わりに takeout)。
- 各職種の語録の版を 0.4.0 → 0.5.0、更新日を 2026-10-01 にした。ゲームの版は 0.30.0(`products.json` の `changelog`)。
- 公開の語数は、180 → 203。職種ごとの語数は、エンジニア 30・営業 35・事務 36・飲食 34・教育 34・接客販売 34。

## バランスの確認

公開前(0060)に、203 語で `tests/balance.test.js` が通ることを確認済み。今回も、`npm run test` で全件通過(クリア率の階段は変わらない)。

## 影響範囲

- 利用者: 5 職種で、英語で表示・英字で入力する語が出る(ローマ字の書き方の設定は、この語には効かない。0056)。
- 記録・ランキング・D1・環境変数・プライバシーポリシーの版: 変更なし。
- テスト: 語数(180 → 203)・確認メモの件数・`--for-ai` の下書きなしの出力に合わせて更新した。
