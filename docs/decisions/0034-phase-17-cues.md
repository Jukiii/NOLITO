## 決定(計画への「推奨案で」)

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 合図の種類 | `surge-warn`(ダッシュの予告)・`surge`(ダッシュ中)・`shock`(ミスで加速中)・`closing`(追い詰め中)の 4 つ。**倍率の計算(`drainMultiplier`)と同じ判断**で決める(`rules.js` の `activeCues`)。予告は、倍率 1(まだ速くならない) | 画面で見える合図と、実際に速くなる時間が、ずれない(テストで、全時刻・全距離について、一致を検査) |
| 2 | 文字での合図 | ゲージの横(「あぶない!」の隣)に、**「ダッシュ注意!」「ダッシュ中!」「ミスで加速中!」「追い詰め中!」**。予告は**破線**の枠、実際に速くなっている間は**実線**の枠(色だけに頼らない)。複数が重なると、決まった順(予告 → ダッシュ → ミス → 追い詰め)で、横に並び、狭い画面では折り返す | 文字と枠で伝える |
| 3 | 読み上げ | 文字の欄は `role="status"`(読み上げの領域)。合図が**増えたときだけ**読まれる: 変わらない合図の文字は、作り直さない(同じ位置の要素は、動かさない)。場面(飾り)は、これまでどおり `aria-hidden` | 入力中の読み上げを、くり返さない |
| 4 | 場面の見せ場(飾り) | 場面の `data-cues` に合図を入れ、CSS で見せる。**ダッシュ注意 = 追ってくる人の頭に「!」(ゆっくり脈打つ)/ ダッシュ中・ミスで加速中 = 速さの線が流れ、追ってくる人が大きくなる(`scale: 1.12`)/ 追い詰め中 = 追ってくる人が少し大きい(`scale: 1.06`)** | 役職の動き(`transform` のアニメーション)を、上書きしないよう、大きさは、重ねられる `scale` で変える |
| 5 | ちらつかない | 動くのは、位置(速さの線の `background-position`)と、大きさ(「!」の `transform`)だけ。色・明るさ・影・不透明度は変えない(0028 の決まり。テストが検査) | 光の点滅を避ける |
| 6 | 動きを減らす設定 | 全体の規則で、アニメーションが止まる。**文字の合図・静止した見せ場(線・「!」・大きさ)は、残る** | 文字が主 |
| 7 | 遊んでいる間だけ | 合図は、`renderStats` が、`status === "playing"` のときだけ出す。終わりの演出・結果・ダッシュボード・やめる・新しいゲームでは、消える(`clearStaging`)。用語確認(追いかけなし)には出ない | 演出と重ならない |
| 8 | **社長の「追い詰め」を、50% → 40% に変更(0033 の決定 8 を置き換える)** | 社長の初期距離は最大の 50% なので、境目が 50% だと、**始まってすぐに「追い詰め中!」が出続けた**(ブラウザ確認で発見)。境目を **40%** にし、社長の `base_gain` を 5.2 → **4.8** に探し直した。最大 ×1.3 はそのまま。会長(初期距離 45%)は、もとから 40% | 始まってすぐは、追い詰められていない |
| 9 | ルールの説明・FAQ | 説明の文は、データから作るので、自動で「40%を切ると」になる。FAQ・更新履歴も直した | 文言とデータを、ずらさない |
| 10 | 影響 | ゲームの規則・距離の式・記録の形と版・スコアの式・語録は、変わらない。**追加は、表示だけ**(社長のルールの境目と `base_gain` を除く) | 見た目が中心 |

## 見つけたこと

- **社長の追い詰めが、始まってすぐに働き続けていた**(初期距離 = 境目)→ 境目を 40% に(上の決定 8)
