# 0075 キャラクターの絵の質感を上げる(Issue #166 PR 7)

## 理由

Issue #166 の運営者のコメント(2026-10-03)「A で、AI の画像生成を使ってでも、クオリティをもっと上げて」を受けた。A は、いまの SVG(図形とグラデーションだけ。0030・0071)の中で、質を上げる方針。

## 変更

- 7 枚の絵に、質感を足した: 服の 2 段目の陰・前の縁の明るい線・ベルトとバックル、手足の陰と光、髪の細い毛筋と影、目の 2 つ目のハイライトと上まぶたの太さ・目尻、線の色を少し濃くした。
- 40KB の上限を守るため、自転車(係長)は、奥の脚の陰・車輪の点を省いた。全 7 枚とも 40KB 未満(最大は `kakaricho.svg` 約 39.8KB)。
- 6 コマのスプライトシートの形式・大きさ・乗り物の種類・動きは変えない。ゲームの画面(play・result・check・dashboard)を撮り直した。

## AI の画像生成について

- Claude Code には、画像を生成する道具がない。AI の画像(ラスター画像)を使うには、「絵は SVG の図形とグラデーションだけ」という規則(0030・0071)の変更が要る(仕様変更)。あわせて、生成サービスの規約・著作権と出どころの記録・費用・サイズ(コマ送りの 6 コマ)を確認する必要がある(CLAUDE.md の作業ルール 7)。
- 運営者の判断が要るため、Issue #166 で確認する。この PR では、規則を変えていない。

## 影響範囲

- 絵のファイルと、詳細ページの画面(画像)だけ。コード・記録・ランキング・バランス・語録は変えない。

## テスト

- `tests/characters.test.js`・`tests/sprite-scene.test.js` を含む `npm run check`。Edge で、1280px・360px・横向き・動きを減らす設定・危ない状態を確認(横はみ出しなし・エラーなし)。

## 未対応

- 絵の好みは、運営者の確認待ち。SVG だけで出せる質には限りがあり、さらに上げるには、B(AI の画像など、別の方式)の判断が要る。
