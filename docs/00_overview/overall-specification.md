# 全体仕様書

## 1. 目的
個人開発したゲーム、ソフトウェア、業務効率化ツール、記事を一つのブランド配下で公開・管理するプロダクトポータルを構築する。

## 2. 初期プロダクト
「上司から逃げろ」タイピングゲーム。
- 仕事・会社関連の用語をローマ字で入力
- 職種を選択すると専用語録を使用
- 先輩、係長、部長、社長、会長（裏ボス）の追跡
- 距離ゲージを実質的な制限時間として使用
- 正解で距離増加、ミス・時間経過で距離減少
- 用語確認モードと連続タイピングモード
- 成績、苦手用語、復習、称号、実績、熟練度を管理

## 3. サイト構成
`/games/`, `/software/`, `/tools/`, `/articles/`, `/downloads/`, `/support/`, `/about/`, `/privacy/`, `/terms/`, `/advertising/`, `/contact/`, `/assets/`, `/data/`, `/docs/`

## 4. アカウント
未登録でも利用可能。未登録データはLocalStorageへ保存し、JSON入出力と登録後のデータ移行に対応する。初回アクセス時に登録案内を表示するが、登録は強制しない。登録後はプロフィール、成績、実績、購入履歴、ライセンスを管理する。

## 5. 将来拡張
管理画面、Googleログイン、オンラインランキング、外部販売サービス、将来自サイト決済、ライセンス認証、チーム対応、AI連携を段階的に追加する。
