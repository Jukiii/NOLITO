# 0067: ゲーム画面を「アーケードゲーム風」にする(Issue #166 PR 1。枠・プレイ中の見た目)

## 背景

運営者が、Issue #166 で依頼した(2026-10-02)。Webサイト風の画面から、アーケードゲーム風の画面への全面的な改修(ドット文字・暗い枠つきの画面・吹き出しの入力エリア・太い光るゲージ・プレイ中はヘッダー・フッター・リンクを隠して四隅の HUD に・点滅する開始画面・ドラムロールの結果画面)。大きいので、3 つの PR に分ける(計画は Issue #166 のコメント)。

- **PR 1(この決定)**: 枠つきの画面・プレイ中のヘッダー/フッターの非表示・HUD・ゲージ・場面・吹き出しの語。
- PR 2: 「PRESS SPACE KEY TO START」の点滅・結果画面のドラムロール。
- PR 3: ドット文字(自前配信の OFL の subset woff2。Google Fonts は、外部への通信になるため、ポリシーの版と同意の取り直しが要る)。

## 決定(PR 1)

- **HTML の構造は変えず、CSS だけで作り直す**(`game.css`)。多くのテストが HTML の並びに依存し、スクリプトの `data-*` の目印も変えないため。
- `.game-play` が、意味のトークン(`--color-bg`・`--color-text` など)を、暗い `--arcade-*` の値に再定義する。子の部品は、どのテーマでも暗い画面になる(`color-scheme: dark`)。`--arcade-*` は `tokens.css` の `:root` にだけあり、**テーマでは上書きしない**(テストが検査)。`.scene` は、淡い背景の絵のために、固定の明るい色に戻す。
- プレイ中(`[data-view="play"]` が見えている間)は、`body:has(...)` で、`.site-header`・`.site-footer` を隠す(ほかのページへのリンクを出さない)。**スキップリンクは隠さない**。「音」「やめる」は、画面の中にいつもある(グリッドの `sound`・`quit` の場所)。`.game-play__side` は `display: contents` で、HUD・ボタンを、グリッドの場所に直接置く。
- ゲージは、太い光る縁と区切りの縞。危ないとき(`isDanger`)は、`gauge-danger`(1.2 秒周期)で脈打つ。語は、しっぽつきの吹き出しにし、打った文字は黄色・太字・下線、残りは薄い色にする(色だけに頼らない)。
- 場面は大きくし、背景を `scene-scroll`(14 秒・線形・無限)で流す。終わりの演出(`data-stage="clear|over"`)では止める。追ってくる人の位置の計算式は、大きさ(`--chaser-w`・`--player-w`)を使う形に変えた(挙動は同じ。「距離が近いほど、近づく」)。
- 用語確認(`data-mode="check"`)も、同じ暗い枠(場面・ゲージ・追跡の HUD は、いつもどおり隠す)。
- 横向きの低い画面(`orientation: landscape` かつ `height <= 32rem`)の規則は、カスケードの都合で、ファイルの末尾に置いたまま。HUD は 1 行、吹き出しの余白を詰める。

## 変えないもの

- ゲームのロジック・記録の形(版 5・キー)・ランキング・演出の順序(結果は演出の前に保存)・音・設定。プライバシーポリシーの版(新しいデータの取得・送信・外部の通信はない)。
- 動きを減らす設定: 流れる背景は止まり、場面は最後の静かな状態になる。色・明るさ・影の動きは、1 周 0.8 秒以上。
- 360px の幅で、横にはみ出さない。タップ領域は `--tap-size`(44px)以上。プレイ画面に、開閉の部品を置かない。

## 影響範囲

- プレイ中は、ヘッダー・フッターが出ない。やめる(または結果)で、戻る。ダッシュボード・結果・成績・プロフィールの見た目は、PR 1 では変わらない(結果画面は PR 2)。
- プレイ画面と用語確認のスクリーンショット(`play.webp`・`check.webp`)を撮り直した。
