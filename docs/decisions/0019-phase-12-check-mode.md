# 0019 Phase 12 PR 1: 用語確認モードと、説明の表示

日付: 2026-09-20 / 対象: Phase 12「役職ごとに初期距離を変更。文字数・難易度・速度で正解時距離増加、ミス・長さで減少。日本語・読み仮名・説明を表示。用語確認／連続タイピングの2モード。復習リスト対応。」

Phase 12 は 3 つの PR に分ける。**この PR(1)**: 用語確認モード・説明の表示・結果の「今回ミスした語」。**PR 2**: 復習リスト(成績ページ・用語確認との連携)。**PR 3**: 距離の計算(難易度・速度)とバランスの再調整(Phase 11 の PR 2 =語録の難易度の統一・語の追加のあと)。

## 仕様と、現状の突き合わせ

| 仕様 | 状態 |
| ---- | ---- |
| 役職ごとに初期距離を変更 | 済み(Phase 3) |
| 文字数で距離が増加 | 済み。**難易度・速度**は PR 3 |
| ミスで距離が減少 | 済み。**「長さで減少」は、下の決定 8** |
| 日本語・読み仮名を表示 | 済み。**説明を表示**は、この PR |
| 用語確認／連続タイピングの 2 モード | 連続タイピング = 従来のゲーム。**用語確認は、この PR** |
| 復習リスト対応 | PR 2(元データ `wordMisses` は、Phase 4 から保存済み) |

## 運営者が決めたこと(計画への「推奨案で」)

1. 順番: PR 1・PR 2 を先に。PR 3 は、Phase 11 の PR 2 のあと
2. 用語確認: 追いかけなし・時間制限なし・罰なし・10 語・保存しない
3. 説明の表示: 用語確認では常に。連続タイピングでは既定オフ(設定で切り替え)
4. 「長さで減少」: (a)長い語ほど、打つ間に時間で距離が減る(すでにそうなっている)。**追加のルールは、作らない**
5. 復習リストの範囲: 直近 20 プレイでミスした語を、ミスの多い順に、最大 20 語(PR 2)
6. 用語確認の結果: 保存しない

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | モードの選択 | ダッシュボードに「モードを選ぶ」(連続タイピング(既定)・用語確認)。**用語確認を選ぶと、「追ってくる人を選ぶ」と「説明の設定」は隠れ**、開始のボタンは「用語確認を始める」になる | 用語確認には、役職・追いかけがない |
| 2 | 用語確認の内容 | 職種を選び、その職種の語から **10 語**(重複なし)。**役職に関係なく、職種の全語**から選ぶ。語ごとに、日本語・読み仮名・**説明**を見ながら、読みを入力する。追ってくる人・時間制限・ゲージは、ない。**ミスしても罰はない**(数えるだけ。何回ミスしても終わらない) | 学ぶための練習 |
| 3 | 画面の作り | プレイ画面(入力欄・語の表示・ミスの表示)を、そのまま使う。追いかけ専用の部品(場面・ゲージ・「追ってくる人」の行)は、`data-chase-only` の印で、用語確認では隠す。ステータスは「確認済み n / 10語」。注意書き「追ってくる人も、時間制限もありません。ミスしても大丈夫です。」を出す | 入力・IME・スマホの扱いを、二重に持たない。用語確認の結果の画面は、別(`check-result`) |
| 4 | 用語確認の結果 | 確認した語数・ミス・正確率・時間。**ミスした語**(ミスの多い順・説明つき)と、**今回の用語**(出た順・説明つき)。「もう一度、用語確認」「ダッシュボードへ戻る」。**保存しない**旨を書く。ランキング・成績・記録・実績には、入らない。広告の枠は置かない | 保存の形(版 2)を変えない。学習の画面に広告を置かない |
| 5 | 説明の表示 | 用語確認では、常に表示。連続タイピングでは、**設定「プレイ中に、用語の説明も表示する」**(既定オフ)。説明の文字は、`textContent` だけで入れる | 連続タイピングは、時間との勝負なので、既定では出さない |
| 6 | 設定の保存 | `nolito:escape-boss:settings:v1`(**記録のキー `nolito:escape-boss:v1` とは別**)に `{ "showExplanation": true/false }`。壊れた値・型違い・知らない項目は、既定に戻す。保存できない環境でも、落ちない | 記録の保存形式(`DATA_VERSION` 2)を変えない。設定は、記録ではない |
| 7 | 今回ミスした語 | 連続タイピングの結果に、「今回ミスした語」(説明つき・ミスの回数)。ミスがなければ、出ない。`wordMisses`(語の id → ミス数。保存済み)から作る。同じ語が 2 回出題されても、1 件にまとめる | 結果を、学習に、つなげる。復習リスト(PR 2)の下地 |
| 8 | 「長さで減少」 | **新しいルールは、作らない**。長い語は、打つのに時間がかかるので、時間による距離の減少が、大きくなる(すでに、そうなっている) | 運営者が(a)を選んだ。ルールを増やさない |
| 9 | 読み上げ | 用語確認では、語が変わるたびに、読み上げの領域(`role="status"`)に「n語目。語。読みは…。説明」を入れる。開始・終了も入れる。画面の切り替えでは、結果の見出しにフォーカスを移す | スクリーンリーダーの利用者が、語と説明を、聞ける |
| 10 | 語録・記録への影響 | **語録のデータは、変えない**。記録の版・形は、変えない(既存の記録は、そのまま読める)。用語確認は、`store` を呼ばない(テストで検査) | 影響を、最小にする |
| 11 | 詳細ページ | ゲームを **0.4.0** に。更新履歴・説明・FAQ を更新し、**画面(スタート・プレイ中・用語確認・結果)を撮り直した**(CLAUDE.md の決まり) | 画面が変わった |
