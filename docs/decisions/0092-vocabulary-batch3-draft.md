# 0092: 語録の増量 バッチ 3 の下書き(Issue #182 / #218)

日付: 2026-10-04

## 背景

語録の目標は、職種ごとに 300 語以上。バッチ 1・2 と同じく、一度に増やさず、確認できる量に分けて追加する。

## 決めたこと

- 6 職種それぞれに 20 語、計 120 語を `content/vocabulary/<職種ID>.ext-batch3.md` に追加した。
- すべて `draft: true` / `review: pending` の下書き。運営者が確認した語だけ公開する。下書きは公開 JSON に入れない。
- id は各職種の前の語の続きから付け、既存の id・語は変更しない。
- `npm run vocab:check` で形式・重複・入力可否を検証し、`npm run vocab:stats` で読みの長さと難易度の一致を確かめる。類似語の候補は目安として、確認シートで人間が確認する。

## 影響

- 公開は 523 語のままで、ゲーム・クリア率・生成済みの公開 JSON は変わらない。6 職種にそれぞれ 20 語の下書きが増えた。
- 下書きは合計 416 語(バッチ 1・2・3)。`npm run vocab:check` の類似語候補は 25 件で、重複とは限らない。`npm run vocab:stats` の警告は 0 件。
- 公開するときに `tests/balance.test.js` でクリア率の階段を再確認し、必要であれば語録の版・ゲームの更新履歴・役職のバランスを見直す。

## 次

確認シートで人間が確認 → OK の語だけ公開 → 300 語に届くまで次のバッチを追加する。
