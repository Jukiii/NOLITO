## Phase 15 と Phase 16 の分担(運営者が決めたこと。計画への「推奨案で」)

- **Phase 15**: 構造・動きの仕組み・役職ごとの動き・背景(**いまの絵のまま**)
- **Phase 16**: 絵(キャラクター・乗り物)の描き直し・セリフ・開始/接近/クリア/ゲームオーバーの演出・音

そのほか決めたこと: ゲージは場面の上へ・役職の動きは 5 種類を CSS で・データ(`roles.json`)で決める・PR は 2 つ。

## 決定

| # | 項目 | 決定 | 理由 |
| - | ---- | ---- | ---- |
| 1 | 画面の並び | 上から **距離ゲージ → 場面 → 単語 → 入力欄**。サイドステータスは、横(狭い画面では下)。狭い画面(< 48rem)の余白を、24px → 16px に詰めた(375×667 で、入力欄の下端が 668px → 644px。スクロールなしで収まる) | 仕様の並び。スマートフォンで、入力欄が見えるように |
| 2 | 役職ごとの動き | `roles.json` の各役職に `scene.motion`。**先輩 = run(走る。速い上下と前かがみ)・係長 = pedal(こぐ。左右に傾く)・部長 = drive(エンジンの振動 + 後ろに流れる煙)・社長 = glide(ゆったり進み、つやが光る)・会長 = aura(浮かび、オーラの脈動と影)**。知らない値・ない場合は、既定(run)。CSS は `.scene[data-motion="…"]`。絵は、そのまま(SVG を、CSS で動かす) | 役職の個性を、絵を描き直さずに |
| 3 | 追ってくる人の構造 | 外側の枠(`.scene__chaser`。位置 = 距離に応じた `left`)と、中の絵(`.scene__chaser-img`。動き)に分けた。煙・オーラ・影は、枠の `::before` / `::after` | 位置と動きが、干渉しない |
| 4 | 道の速さ | 追ってくる人が近づくほど、道が速く流れる(1 周 0.9 秒 → 0.4 秒。`--closeness` から CSS で計算) | 距離の表現を、動きでも伝える |
| 5 | 危ないとき | 距離が最大の **25% 以下**(ゲージと同じ判断 `isDanger`)で、場面の縁が、ゲージと同じ黄色(トークン `--color-accent`)で、ゆっくり(1.2 秒)脈打つ。「あぶない!」の文字は、これまでどおり | 色だけに頼らず、縁の太さ・文字でも示す |
| 6 | 一瞬の演出 | `view.pulseScene(kind)` が、`[data-event]` を 350ms だけ付ける。**miss**(ミス): 追ってくる人が、ぐっと飛び出し、あなたがのけぞる。**gain**(正解): 道が速く流れ、追ってくる人が、すっと下がる(移動を 0.3 秒に)。用語確認(場面がない)では、出さない | 緩急。ミスと正解が、動きでも、わかる |
| 7 | 動きを減らす設定 | 全体の規則(`base.css`)でアニメーションが止まる。動く飾り(部長の煙)は、静止すると不自然なので、消す。**位置は、距離に応じて、これまでどおり変わる**。危ないときの縁(太さ 0.25rem)は、脈打たずに残る | 動きが苦手な人にも、距離が伝わる |
| 8 | ちらつき | 色・明るさ・影を変えるアニメーションは、**1 周 0.8 秒以上**(テストで検査)。速い細かい振動は、位置だけ(部長のエンジン 0.1rem) | 光の点滅を、避ける |
| 9 | 純粋なロジック | `scene.js`: `closenessOf`・`isDanger`・`motionOf`・`SCENE_MOTIONS`・`SCENE_EVENTS`。DOM・時計に触れない | テストしやすい |
| 10 | 詳細ページ | ゲームを **0.12.0** に。更新履歴・FAQ「画面の動きが、苦手です。動きを止められますか?」。遊ぶ画面の画像(`play.webp`)を撮り直した | 画面が変わった |
| 11 | 影響 | **ゲームの規則・距離・バランス・スコア・記録・語録は、変わらない**(バランスのテストは、そのまま成功) | 見た目だけ |

## テスト

- 新規 `tests/scene.test.js`(21 件): 位置・危ない(ちょうど 25% を含む境界・最大距離が違っても)・**ゲージと場面が同じ判断を使う**・動き 5 種類(5 役職すべてが、違う動きを持つ)・壊れた値でも既定・画面の並び(ゲージ → 場面 → 単語 → 入力欄 → ステータス)・場面は飾り・絵に大きさと空の alt・**CSS のアニメーション名が、すべて `@keyframes` で定義され、使われていない定義もない**・**色・明るさ・影のアニメーションが、1 周 0.8 秒以上**・動きを減らす設定・色はトークン・危ないときの縁が残る・`main.js`・`view.js` のつなぎ・`scene.js` が純粋
- ブラウザ(headless Edge + `wrangler pages dev`、**実際のキー入力**)**34 項目成功**: 画面の並びと位置(デスクトップ・768px・375px)・**5 役職それぞれの動き(計算されたアニメーション名・絵・煙・オーラ・影)・実際に動いている**・距離に応じた位置・**近づくほど道が速い**・危ない(場面とゲージが同時・黄色の縁・文字)・**ミスの演出と正解の演出・元に戻る**・用語確認では出ない・最後まで遊べる(記録は版 3)・**動きを減らす設定(アニメーション ≈ 0 秒・煙は消える・位置は変わる・縁は残る)**・375px で横スクロールなし・外部通信なし
- 見た目: 5 役職のスクリーンショットを目で確認(先輩・部長(危ない)・会長(オーラ))

## 見つけたこと

- **確認に使うヘッドレスの Edge は、既定で「動きを減らす」設定になっていた**(この環境の OS の設定のため)。動きの確認は、`prefers-reduced-motion: no-preference` を、明示して行う。この環境で作った以前の確認では、動きは、止まった状態だった
