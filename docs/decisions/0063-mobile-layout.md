# 0063: スマホのレイアウト(横幅 100%・下部固定バーの廃止。Issue #154)

## 背景

運営者が、Issue #154 で、スマホで次の 2 点を依頼した(2026-10-01)。

- 横幅が少し大きく、画面の横にずれる(スクリーンショットで、左が切れ、右に余白が出ていた)。「スマホでの横幅は 100% にして欲しい」。
- ホーム・ゲーム・ツール・記事の下部固定バーは要らない。「ハンバーガーメニューだけでいい」。

## 原因

- ゲームのダッシュボードの「プロフィール」のフォーム(`.profile-form`・`.profile-form__field`)は、列を決めないグリッドだった。ニックネームの入力欄の本来の幅(約 386px)で列が広がり、幅 375px の画面を超えていた(幅 375px の Edge で再現・確認)。

## 決定

- 下部固定バー(Phase 20 PR1 の `bottomNav`・`components/bottom-nav.js`・CSS・トークン `--bottom-nav-height` `--z-bottom-nav`・Phase 22 PR1 の `data-hide-bottom-nav`)を廃止した。ナビは、ヘッダーのハンバーガーメニュー(サブメニューつき)だけ。`.main` の下の余白も、もとに戻した。
- プロフィールのフォームの列を `minmax(0, 1fr)` にした。
- 同じことが、ほかの画面でも起きても、横にずれないよう、`html`・`body` の `overflow-x`、`select`・`input`・`textarea` の `max-width: 100%` を、`base.css` に足した(安全網)。

## 影響範囲

- 0045(Phase 20)の下部固定バーの部分と、0047(Phase 22)の下部バーを隠す部分は、置き換わった。ほかのナビ(PC のドロップダウン・ハンバーガー)は、変更なし。
- 記録・データ・API は、変更なし。プライバシーポリシーの版も、変更なし。

## テスト

- `tests/mobile-input.test.js`(横幅の指定・バーがないこと)・`tests/nav.test.js`・`tests/site.test.js` を更新。
- 幅 360・375・402px(ライト・プリティ・ダーク)で、全 16 ページに横のはみ出しがないことと、ハンバーガーメニューが開くことを、ブラウザで確認。
