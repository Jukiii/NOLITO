# AI改善提案用プロンプト

次の語録の YAML(`docs/04_templates/vocabulary-template.md` の形式)は、**すでに公開している語**(下書きではない)。関連用語・学習ポイント・詳細説明のいずれも、まだ持っていない。それぞれの語について、**関連用語(`related_terms`。同じ職種の、ほかの語)・学習ポイント(`learning_points`。5個まで各60字)・詳細説明(`detail`。難語だけでよい。300字まで)**の追加案を提案すること。ただしAIの提案を最終判断にせず、人間による最終確認を必須とする。

- 語ごとに、`id` と、提案の内容を書く。**提案がない語は、書かない**(すでに十分な語もある)。
- 関連用語は、渡した語録の中に、実在する日本語表記だけを挙げる(存在しない語・ほかの職種の語を挙げない)。
- 意味・法令・制度に関わる提案は、確信が持てない場合は、「確認が必要」と明示する(推測で正しいと言わない)。
- **原稿そのものを、書き換えない**。提案は、別に書く(人間が、原稿に反映するかどうかを決める)。
