# 0054: Phase 29(広告・アフィリエイト・収益化)の計画

## 背景

仕様(`docs/01_phases/phase-29.md`)は「広告+アフィリエイト。ゲーム外・終了画面・記事に掲載。外部販売から開始し将来自サイト決済。リンク情報をデータ化し管理画面で管理。収益化ポリシー・広告基準・必要表示」と、高レベルの列挙。広告事業者の契約・審査・費用・ポリシーの版(同意)に関わるため、段階導入にする(Phase 27・28 と同じ)。最初の PR の範囲は、運営者に確認し、**方針の文書と表示だけ**(広告事業者のスクリプトは入れない)に決めた。

## PR の分け方

1. **PR1(この PR)**: 収益化ポリシー・広告基準・必要表示の文書(公開ページ `/ads-policy/`)。
2. PR2 以降(範囲は、着手前に確認する): アフィリエイトのリンク情報のデータ化と、「広告」「PR」の表示つきの部品 → 管理画面での管理(Phase 26 のプロダクト管理と同じ形)→ 広告事業者のスクリプト(契約・審査・ポリシーの版・同意の拡張が先に必要)。

## PR1 の決定

- **`/ads-policy/`(新設。`public/ads-policy/index.html`)**: 現在の状況(広告もアフィリエイトもなし)・考え方(外部販売から。自サイト決済は対象外)・載せる場所と載せない場所・必要な表示・広告の基準(掲載しないもの)・始める前に行うこと・変更・問い合わせ。フッターに「広告・収益化について」を追加(`config/nav.js`)。`/smoke` の確認対象にも追加した。
- **載せる場所は、既存の広告枠のルール(`components/ad-slot.js` の `AD_PLACEMENTS`)と同じ**(ゲームの外のページ・記事・結果画面。プレイ中は不可)。文書に、個人情報を入力するページ(問い合わせ・アカウント)にも置かない、と足した。
- **プライバシーポリシーの版は、上げない**(版 4 のまま)。§5 に、この文書へのリンクを 1 文足しただけで、個人情報の取り扱い・計測の内容は変わらない(CLAUDE.md の版の基準)。広告の配信で情報を取得・共有するようになるとき(PR 以降)に、版を上げて同意を取り直す。この文書の「始める前に行うこと」に、そのことを書いた。
- **文書の内容は、AI(私)の下書き**。掲載しない広告の種類・表示の文言・報酬の書き方は、運営者が確認する(特定商取引法・景品表示法・ステルスマーケティング規制の観点で、必要なら専門家に確認する)。

## 影響範囲

- 利用者に見える変更: 新しいページ 1 つ・フッターのリンク 1 つ・プライバシーポリシー §5 の 1 文。広告事業者のスクリプト・Cookie・計測は、増えない。D1 のマイグレーション・環境変数の変更もない。

## テスト結果

- `tests/ads-policy.test.js`(6 件): リンク・「現在は掲載していない」がプライバシーポリシーと食い違わないこと・外部スクリプトを読まないこと・載せる場所が `AD_PLACEMENTS` と合っていること・必要な表示・検索用の情報。
- `tests/contact-page.test.js` のフッターのリンクの期待値を更新。`npm run check` 通過。
