「キーみち」は、キーボードだけで作業するための「キー操作ルート」を、自分の作業手順に合わせて組み立てるツールです。登録は要りません。ブラウザですぐに使えます。

ショートカットキーは、一覧を眺めるだけでは身につきにくいものです。自分がよくやる作業の流れに沿って、順番に並べて練習すると、手が覚えやすくなります。キーみちは、そのための道具です。

## 基本の流れ

[キーみち](/tools/kii-michi/)の画面には、「操作」「ルート」「練習」「一覧」「チートシート」「設定」の6つのタブがあります。使い方の流れは次のとおりです。

1. 「操作」で、使うアプリと、よく使うキー操作を登録します。
2. 「ルート」で、登録した操作を、自分の作業の順番に並べます。
3. 「練習」で、ルートの手順を、順番どおりに、キーを押して練習します。
4. 「一覧」で、登録した内容を確認します。
5. 「チートシート」で、印刷や保存をします。

## 操作を登録する

「キーを押して入力」を使うと、実際にキーを押して、その組み合わせを登録できます。1回の操作で、押した1つ分が入ります。Esc キーか、ほかの場所のクリックで、いつでも入力を終えられます。

キーは、文字ではなく、キーボード上の「位置」で読みます。そのため、表示するキー名は、アメリカ式(US 配列)のラベルです。日本語配列のキーボードでは、記号の印字が違うことがあります。

ブラウザや OS が先に処理するキー(たとえばタブを閉じる Ctrl+W)は、押しても登録できません。その場合は、文字で入力します。

## ルートに並べて、練習する

ルートは、「メールを開く → 返信する → 送信する」のように、自分の作業の順に操作を並べたものです。ルートに並べておくと、「いまの作業で、次に使うキー」がひと目でわかります。

「練習」では、ルートの手順が、順番に出ます。答えの枠にフォーカスを置いて、実際にキーを押すと、合っているか違うかが表示されます。ブラウザや OS が先に処理するキーや、キーを押しても反応しない操作は、答えを見て自分で確認する形になります。やめたくなったら、「やめる」ボタンで中断できます。練習の結果は、保存されません。

## チートシートにして持ち歩く

「チートシート」では、「操作ルート」と「アプリ別のショートカット」を選んで、自分用の一覧表を作れます。

- 印刷、または PDF に保存
- Markdown をコピー
- Markdown ファイルとして保存

デスクの横に貼る紙としても、メモアプリに貼り付ける文章としても使えます。

## 保存とバックアップ

登録した内容は、お使いのブラウザの中にだけ保存されます。サーバーには送信しません。そのため、ブラウザのサイトデータを消すと、登録した内容もなくなります。

「設定」のタブから、JSON ファイルとして書き出せます。機種を変えるときや、念のためのバックアップに使ってください。読み込むと、いまのデータが、読み込んだ内容に置き換わります。先に書き出しておくと安心です。

キーの表記は、Windows(Ctrl / Alt / Win)と macOS(Control / Option / Command)から選べます。変わるのは表記だけで、登録した操作の中身は変わりません。

## ショートカットの辞書は入っていません

キーみちには、アプリごとのショートカットの辞書は入っていません。ショートカットは、OS やアプリのバージョンによって違い、正確さを保てないためです。自分が使っているアプリで、実際に使っている操作を登録してください。

プライバシーの扱いについては、[プライバシーポリシー](/privacy/)に書いています。
