# 0079 スタート前の難易度の選択欄を、また外す(Issue #173)

日付: 2026-10-03

## 理由

0076 で、Issue #173 の「職種と難易度が選べなくなった」を、「やさしい・ふつう・むずかしい」の選択欄を戻す意味だと受け取って、戻した。その後、Jさんが「ここでいってる難易度は役職の話やから"難易度"はいらない」とコメントした(2026-10-03)。つまり、Jさんの言う「難易度」は、追ってくる人(役職)のことで、別の「難易度」の選択欄は要らない。0076 は、この回答で取り消す。0061(難易度 = 追ってくる人)に戻る。

## 変更

- スタート前のフォームから、「難易度」のドロップダウン(`data-difficulty-list` ほか)を外した。`view.js`・`main.js`・`index.html` を、0076 の前の形に戻した。
- プレイはいつも「ふつう」(`DEFAULT_DIFFICULTY`)。自己ベストの表示も、ふつうの記録。
- 0076 の決定ログは、履歴として残す(この決定で取り消し)。
- ゲームの更新履歴(`products.json`)を 0.32.0 に。ダッシュボードの画面を、前の形に戻した。

## 影響範囲

- 画面のつなぎだけ。難易度の中身(`difficulties.json`・`difficulty.js`)・記録・ランキング・実績・経験値は、変えていない(0037)。記録の版(`DATA_VERSION` 5)・キー(`v1`)・プライバシーポリシーの版も、そのまま。
- ランキングの難易度の選択欄(プレイヤー・記録のページ)は、残っている。

## テスト

- `tests/difficulty-wiring.test.js`(0076 の前の形に戻した)を含む `npm run check`。
